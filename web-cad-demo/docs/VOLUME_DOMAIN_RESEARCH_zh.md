# 离散几何体域分区算法

算法已能将闭合 Solid 的离散表面分成体积互不交叠的归属区域，再分别导出每个连通体的外壳与空腔壳。相邻连通体复用同一组三角面，原始 Body、Solid、面及三角面来源继续保留。实现现位于[正式体域分区组件](VOLUME_PARTITION_WORKER_zh.md)，实验入口复用同一核心。这些公共边界已用于独立的 [Gmsh 四面体原型](VOLUME_TETRA_RESEARCH_zh.md)，尚未接入工程体域任务、材料分配或日常服务。

## 分区方式

先复用现有 CGAL 表面重构核心，得到共形三角面及原始来源。按 Body 和局部 Solid 标签恢复各输入 Solid 的有向闭合壳；开放、非流形、方向冲突或没有正体积时拒绝，不凭距离猜测内外。

固定使用 CGAL 6.1.2 的 Nef 精确集合运算，增量计算各 Solid 的独有区及交叠区。每个区域保存覆盖它的输入 Solid 集合，例如 A、B、A 与 B。分区后用精确集合比较证明区域两两没有体积交叠，且包含某个输入 Solid 的区域合并后等于该 Solid。Nef 的集合运算语义见 [CGAL 官方说明](https://doc.cgal.org/6.1.1/Nef_3/classCGAL_1_1Nef__polyhedron__3.html)，实际编译采用固定 6.1.2 源包及头文件摘要，不跟随最新版升级。

区域边界直接取自最初修复的共形表面，不将 Nef 的精确交点再次转成小数并重建一套三角面。对每片三角面使用精确集合包含和相交检查，确认整片位于某区域边界；若只有一部分属于该区域或落在区域内部，明确要求继续分割，不用中心点或偏移采样猜归属。

外边界只被一个区域引用，共享界面必须被两个区域以相反方向引用。所有区域共用全局点和三角面编号，因此共享界面不是两份坐标接近但拓扑独立的网格。原始 `sourceTriangleIds` 和 `sources` 直接保留，切割形成的界面仍追溯到实际提供该面的输入，而不冒充目标 Body 的旧面。

## 体积和连通性

集合与体积检查针对修复后的离散几何，不是原始 CAD 曲面的严格体积认证。原型检查每个区域的有向闭合边界、正体积、精确分区体积与最终三角面体积差异，并核对每个原始 Solid 的体积覆盖；相对体积误差门限为 1e-8。原有 CAD 曲面的严格距离界仍未认证。

同一归属组合可能包含多个不连通体。例如 A 被贯穿薄体 B 切开后，“只属于 A”的区域可能有两个连通部分。输出保留区域的 `connectedVolumeCount`，并通过 `cells` 分别导出三个实际连通体，不把一个归属区域等同于一个连通实体；`connectedCellsIndividuallyExported` 为 true。

每个连通体由 Nef 实际标记体的壳构造：对各有界壳做对称差并正规化，不依赖壳的枚举次序，也不采样中心点。检查每个结果恰好有一个连通体、属于原区域、与其他结果无正体积交叠，合并后精确等于原区域。边界三角面随后按共享边建立壳，要求一个正向外壳、其余为负向空腔壳，壳数与 Nef 结果一致。输出 `triangleCellUses` 保留公共面的反向使用关系。

交叠区域保留多个输入 Solid 标签，不自动选择某个材料。材料优先级、冲突提示和用户决策规则仍需在工程层完成。

## 已验证范围

29 组检查覆盖单体、分离、交叠、面接触、边接触、点接触、完全重合、包含空腔、嵌套空腔、三个交叠体、断开的同归属区域、旋转相交、一个 Body 内多个 Solid，以及不同 Body 重用局部 Solid 标签。嵌套样本的三个体域体积为 56、7、1，总体积为 64。另复用此前实际 CAD 内核导出的交叠体来源快照，核对其完整清单、原凭据和输入摘要；本轮没有重新导出或修改日常 CAD 工程。

独立脚本检查全局点和三角面唯一性、区域与连通体归属一致、每片边界面恰好进入一个所属壳、每个壳连通且边恰好有两次反向使用、共享三角面的方向、直接积分体积、逐区域和逐源体积覆盖，以及原始面三角形的面积覆盖及支持面偏差。内存中的错误方向、伪造体积、缺失来源、错误面标签和重复三角面均被检查器拒绝。

首轮关闭优化的构建出现模板链接错误，采用项目既有 Release 优化设置后完成构建，原失败日志保留。早期“再次转换分区边界后联合重构”在旋转样本上触发严格来源覆盖失败，现改为原共形表面上的精确集合归类；没有放宽原始来源断言或修改第三方源码。前批凭据保留在 `.artifacts/volume-domain-result.json`；当前连通体与四面体验证的汇总为 `.artifacts/volume-tetra-result.json`。

## 研究预算与边界

| 项目 | 当前限制 |
| --- | --- |
| 输入 Solid 标签 | 最多 6 个 |
| 输入三角面 | 最多 4096 |
| 归属组合区域 | 最多 32 个，不代表最多 32 个连通体 |
| 单独导出的连通体 | 最多 128 个 |
| 共形表面三角面 | 最多 20000 |
| 三角面与区域比较 | 最多 100000 对 |
| 单次集合顶点 | 最多 100000 |
| 请求和回复 | 8 MiB 和 64 MiB |
| Windows 提交内存 | 默认 2 GiB，沿用不可关闭的内存保护 |
| 验证脚本计算时限 | 120 秒，超时停止原进程并等待实际退出 |

自由 Sheet、开放壳、方向歧义和超预算输入会拒绝，当前不能宣称支持任意脏几何。体域分区阶段仍只发布边界和归属，不发布网格成功，因此该阶段的 `tetrahedralReady` 和 `normalMeshAdmitted` 均保持 false。后续独立 Gmsh 原型已生成真实四面体，但没有正式工程任务准入、取消恢复或质量合格承诺。
