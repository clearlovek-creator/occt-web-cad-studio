# 抑制恢复中的远端拓扑证据

状态：2026-11-17，独立内核候选，未部署。特征抑制时保存的整组面边引用现在可以保留远端拓扑证据；恢复后的几何发生变化时，只有证据唯一匹配的面边才能重新关联属性。最终版本和验收记录见 `.artifacts/topology-lifecycle-result.json`。

## 解决的问题

单个持久引用已经能区分“直接邻面相同、远端生成来源不同”的两个面，但抑制存档此前没有保存这份区别。因此同一个面作为下游引用可以恢复，作为抑制存档却仍未关联。真实 OCCT 用例已在旧实现复现这个差异；不是已证明旧实现把属性挂到了错误面上。

现在整组捕获复用同一套两轮邻接细化，只有完整、重复近邻中的唯一远端结构才保存可选证据。交换实体顺序、大幅移动或改尺寸后，恢复解析可以继续找到正确实际面或边。原分支消失、只剩相似的另一分支时，原属性保持孤立；出现两个相同候选或来源不完整时也不自动恢复。

## 格式和旧工程兼容

`selectionSet` 仍为版本 1，每个条目可增加 `remoteContext`，其格式与单个持久引用一致：版本 1、依据 `adjacent-face-refinement-2-v1`、64 位小写十六进制摘要及唯一匹配计数 1。未知版本、错误依据、缺失字段、非法摘要和矛盾的唯一计数会被拒绝，即使几何完全未变也先检查扩展格式。

没有扩展的旧存档保留原规则：精确 BRep、生成身份与生成定义均符合时仍可恢复；几何改变后不能补造原本没有的远端证据。精确归档重新认证可以读取这些旧存档，仍核对原始完整依据，并在审计记录中原样保留旧证明。带扩展的存档则必须同时符合已有扩展，不能借旧格式兼容跳过校验。

普通唯一生成角色和既有一圈邻接规则不变。没有改变属性原锚点、生成面命名根、`SelectionProof` 的授权范围，或现有一对多属性继承策略。

## 工作额度

每次整组捕获或解析共用最多 1000000 工作额度，面与边不分别重置，最多尝试 100000 个面边条目。远端细化及候选索引只构建一次；索引未完整生成时，不发布部分证据或据此判定唯一。内部可降低额度，不能关闭或提高上限。

16 MiB 整组证据和 17 MiB 抑制证明原有限额继续有效。这些保护不等于整个特征批次、基础邻接计算、BRep 读取或内核进程总内存的硬上限。恢复不按距离、面积、尺寸或旧枚举序号猜测。

## 验证范围

新增原生断言在真实 Compound 中组合两个 Solid，使用可控的重复近邻和不同远端生成身份。面与边经过 JSON 往返、私有特征保存、所有权验证和属性存储往返后，属性值只恢复到唯一的正确实际子形状。另检查旧存档、精确重新认证、低额度、错误剩余分支、重复当前分支、缺失来源、六类非法扩展及不匹配摘要。解析出的实际边仍可生成有效圆角。这是具有合成生成身份的真实几何夹具，不是客户生产模型集。

独立真实工程链路继续检查连续两次布尔、两次上游改参、端面和孔壁面积、质心、边长、原生与类型化属性、Gmsh 边界传递、Undo/Redo 和便携工程重开。该链路验证整体兼容，不冒充所有新增远端证据在原生工程包、导入和复杂生成特征中的生命周期均已覆盖。

最终 2056 项应用及 94 项 Python 回归、30 项继承专项、16 项几何及 3 项网格 CTest、封存候选 8 项真实工程链路通过。同一新内核搭配未改动的封存界面，通过 13 项独立页面、55 项工作台和 8 项历史引用流程，页面异常为零；类型检查与本次修改的 JavaScript 文件检查通过。

首次接口验收因受限运行环境拒绝本机连接而中止，保留日志和私有材料；核验身份后仅停止该测试进程树。允许本机通信的隔离环境下完整回归通过，没有改网络配置或加产品重试。初次属性断言误把保留的历史记录当作当前记录，以及浏览器验收模式参数错误，也分别保留失败日志后修正测试准备，没有放宽产品断言。

日常 R222、Box10、295 份保护文件、完整 Pi 历史、前后台服务与默认内核保持。复杂生成身份、任意深度拓扑歧义、全部生命周期、脏离散表面重构、工业规模 GPU 和完整安装升级仍需继续。
