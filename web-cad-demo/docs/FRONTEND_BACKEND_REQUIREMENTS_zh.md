# OCCT Web Studio 前后端需求基线

本基线覆盖 `web-cad-demo` 的工作台、Gateway、OCCT/Gmsh Worker，以及独立 `web-cad-agent` 与 Web 助手的接口边界。模块内的「验收」描述目标行为。代码以当前工作目录为准，已确认的需求中仍有待实现项。

[前端 UI 功能明细](#前端-ui-功能明细)包含 Ribbon 入口、表单字段、视口与工程树联动、任务状态和待确认的交互。
[弹窗与临时界面审核](#弹窗与临时界面审核)列出操作窗、确认、菜单、预览及系统选择器的现状、缺口和验收场景。

## 1. 工程与文件

| 入口 | 前端行为 | 后端约束 |
|---|---|---|
| 保存工程 | 未命名工程先输入有效名称。已命名工程直接保存。校验通过后提示已交给浏览器下载。 | 绑定本次工程和状态生成 `.cadproj`，保留可查询的原任务与备份回执。普通保存生成备份后更新该工程的备份状态。 |
| 另存为 | 输入副本名称并下载 `.cadproj`，下载后继续编辑当前工程。 | 将副本名称写入导出的文件元数据。源工程名、`documentId` 与当前页面身份保持原样。打开该文件时再按普通打开流程建立独立工作区。 |
| 新建、打开、恢复其他工程 | 当前工程有 `*` 时提示「保存后切换」「直接切换」「取消」。保存后切换沿用首次命名流程，交给浏览器下载后才切换。 | 目标工程成功载入后才激活。取消、保存失败或结果待核对时继续显示原工程。直接切换后原工程仍可从恢复列表打开。 |

`*` 表示当前工程与上一次生成工程备份时的状态不同。后台恢复快照和浏览器本地备份是两项能力。

**现状与缺口**　普通保存、首次命名和另存为均已接入独立流程。新建、打开、恢复共用按源工程身份与状态校验的切换确认。副本可从源工程备份管理中下载，生成副本后源工程的备份状态保持原值。

**验收**　另存为后，副本重新打开显示输入的名称，原工程名称和身份保持原样。带 `*` 的工程分别验证取消、直接切换、首次命名后保存切换及保存失败。坏工程包加载失败后原视口和工程树仍可操作。

## 3. 基础建模与吸附

| 阶段 | 前端行为 | 后端约束 |
|---|---|---|
| 构造底面 | 在当前构造坐标系的局部 XY 平面确定落点。鼠标命中平面内的可见端点或边中点时，明确高亮吸附目标。未命中时按网格步长定位。 | 提交与预览使用同一组局部位置、尺寸、坐标系和吸附结果。几何吸附后的精确位置应保留。 |
| 定高与提交 | 需要定高的形状沿局部 Z 方向调整高度，网格步长控制定高。预览显示最终使用的尺寸和位置。 | 用既有建模命令生成 BRep，并校验参数和构造坐标系。 |
| 跨平面 | 只捕捉当前构造面内的端点或边中点。几何点距平面超过容差时回退到网格。 | 几何候选来自当前工程的拓扑。曲边中点应从真实曲线计算，不能取渲染折线端点的平均值。 |

**实现**　几何吸附默认启用。OCCT 提供 BRep 端点及沿真实曲线的半弧长点。工作台在当前构造面的容差范围内，以 9 CSS 像素为捕捉半径，优先选距离鼠标最近的可见候选。同距时优先端点，再按深度排序。平面基础容差为 `0.000001 mm`，远离原点时随浮点精度放宽。底面位置和尺寸保留吸附坐标，定高继续使用网格步长。

**验收**　在旋转过的构造坐标系下，用 `1 mm` 步长拖拽底面并定高。对齐平面内一个不在整毫米网格上的可见端点时，预览和 OCCT 结果落在该端点。平面外可见点和隐藏体上的点不会抢占网格捕捉。

## 4. 变换、布尔与高级特征

- 并集、差集、交集默认消耗工具体，用户可勾选「保留工具体」。压印始终保留工具体，前端应显示固定规则，避免呈现可以关闭的控件。
- 布尔面板展示目标体与工具体，后端禁止同一个 Body 同时属于两组。结果按现有 `keepTarget`、`keepTool`、`splitResults` 规则发布到工程树。消耗的输入仍参与特征依赖与历史重算。
- 变换和高级特征沿用各自的目标选择及参数校验。前端提交体／面／边引用时带上选择所依据的工程状态，Gateway 和 Worker 校验后再写入。历史编辑按 Feature 依赖重算。

**现状与缺口**　布尔面板和内核都已默认 `keepTool=false`。压印的「保留 Tool」已固定为勾选且不可修改，前端提交与内核规则一致。面和边引用重算沿用现有持久命名与血缘逻辑。

**验收**　用圆柱给长方体切孔。默认成功后圆柱退出当前结果树，勾选保留时圆柱仍可选择。撤销后恢复原输入。压印工具体始终保留。输入状态过期或运算失败时不发布部分结果。

## 5. 工程树与属性

- 左侧工程树保持紧凑，保留既定分类和顺序。选择 Body 时联动视口与属性面板，展开 Body 可看特征历史。基础体创建特征用 `createBox` 一类标签表达操作。建议将标签放在显示层映射，持久化 `FeatureId`、命令类型和 Body 名仍各自使用原有字段。
- 新建集合型属性时，默认跟随全部经过拓扑血缘验证的子面或子边。单目标属性遇到分裂、有歧义、原拓扑删除或证据不足时，保留属性值并要求复核。已有属性类型沿用其已保存的分裂策略。
- 手动定位只使用当前、有效的关联身份。候选结果在复核界面展示，不能仅凭重算后的面／边编号选择目标。

**现状与缺口**　新建面／边集合类型默认采用 `all-descendants`，创建时可选择 `review`。已有类型继续使用其保存的策略。基础体与基础面特征已有 `createBox` 一类显示标签，需要覆盖新建及旧工程回归。设计交接中的「仿真管理」分支尚未出现在当前工程树。

**验收**　新建集合型「入口」属性，关联一个面，再将该面分裂为两个经验证的子面；两个面均能定位到该实例。相同操作下单目标实例进入待复核，值仍存在。打开旧工程时，已保存的 `review` 策略仍有效。

## 6. STEP 与来源管理

- 「导入 STEP」向当前 `documentId` 追加零件，新增 Body 和导入特征。现有 Body、特征历史及属性继续可用。
- 导入成功后刷新同一工程。一次导入作为整体完成。失败或取消不留下部分 Body，结果待核对时用原任务 ID 查结果。
- 后端为每次导入保留可验证的来源与特征绑定，多次导入不得混淆来源。新增 Body 使用独立身份，重算、撤销／重做与工程包保存／恢复都能区分各次导入。现有 STEP 导出行为沿用独立入口。

**实现**　`CadDocument::ImportStep()` 从当前事务检查点载入暂存 XCAF 文档，在其中追加一条导入特征及其 Body。Gateway 核对原有 Body、特征、参数和属性记录后提交。导入报告的 Body 数量是本次新增数量。每次导入分别绑定带指纹的 STEP 来源，工程包保存及重开时按特征 ID 归档并重新绑定。STEP 源文件的长度单位会转换成毫米。显式声明其他建模单位的旧 XBF 暂不支持混合追加。

**验收**　有模型和属性的工程连续导入两个 STEP。两次新增 Body 能和原模型共同选择、布尔及划分网格。撤销最后一次导入只移除其新增结果，重做可恢复。损坏文件和取消不改变原工程。保存后重新打开可读取两份来源对应的特征。

## 7. 检查、修复与测量

- 有效性检查和测量为只读操作，结果按工程、对象和版本显示。切换对象或工程状态变化后，显示目标变更或结果过期。
- 修复结果只供预览和剖分。退出预览恢复原 CAD 显示。用户可对照修复前后、定位原始问题，并选择已验证的修复快照作为剖分输入。CAD 几何、特征历史及原属性关联保持原样。
- 后端校验快照身份、来源及可用状态。过期快照或缺失证据时拒绝复用。

**验收**　诊断一个可修复的模型，打开并退出预览，确认工程状态和历史未变化。使用有效快照剖分后再修改原几何，旧快照和旧测量结果不会显示为当前可用。

## 8. 体网格

- 工程体网格只支持全工程共形剖分。隐藏 Body 也参与。面板在启动前明确写明范围，局部 Body／Face 加密只改变目标单元尺寸。
- 剖分任务绑定工程几何、来源与执行方案。前端分别呈现任务完成、来源有效和验收通过，网格质量或来源失效时，按既有规则显示诊断和限制可用结果。
- 网格的显示开关及选中范围在视口生效。网格计算输入仍由全部工程几何决定。

**验收**　用两个接触的 Body 测试，其中一个隐藏。任务显示全工程范围，后端结果包含两者且核对共形界面。对一个 Face 加密后，两者仍都参与。停止或失败后保留可核对的任务状态。

## 9. 命令日志、历史与恢复

- Gateway 按工程保留近期写入命令的运行状态和终态。持久记录包括请求 ID、操作、时间、状态、错误码，日志不包含建模参数。刷新页面或重启服务后，前端能加载当前工程的记录。
- 成功、失败、取消、待核对独立展示。客户端超时或断线后的待核对记录使用原请求 ID 或任务 ID 对账。由后台事务、历史或任务回执确认终态。
- 工程 Undo／Redo 继续以后台历史为准。命令面板的清空操作与用于恢复的工程历史应解耦。

**实现**　工程级写入日志保留最近 200 条已结束记录，并继续保留执行中及待核对记录。面板按当前工程读取 Gateway 日志，展开记录可查看原请求 ID 和适用的任务 ID。核对通过只读查询读取任务或提交证据。日志启用后接收的命令开始纳入，页面内的只读查询仍可用于当前会话诊断。

**验收**　分别提交成功、失败、取消和回复中断的命令。刷新页面及重启后台后，按工程查看四种结果。对待核对的命令重复查询时，模型没有新增几何或历史事件。

## 10. Web 助手、CLI 与运行发布

| 场景 | 前端／调用者 | Gateway 约束 |
|---|---|---|
| 查询和单次创建 | Web 用户明确下达创建基础体的指令后，Pi 可直接执行，通过工具回执报告结果。只读查询直接执行。 | 校验工具参数、工程状态与请求身份。 |
| 影响已有模型的指定操作 | 删除 Body、消耗工具体的布尔、批量修改已有对象先展示操作和受影响对象，再由用户确认。 | 校验确认对应的工程状态和具体操作。输入或状态变化时重新核对并展示，确认记录与提交保持一致。 |
| 其他调用入口 | Web 助手使用 Pi RPC＋CAD MCP，独立 CLI／TUI 通过 HTTP Gateway 调用并沿用其写入审批。 | 两者仍共用 Gateway 与 OCCT 事务能力。存量 Python／LangGraph Web 兼容实现不作为当前 Web 助手的运行链路。 |

**实现**　Web 助手在删除 Body、消耗工具体的布尔、多目标布尔和批量修改现有 Body 时，先在聊天中显示操作与受影响对象。批量修改使用 `batch_modify`，支持 2 到 16 步，在同一事务中提交。Gateway 将确认绑定到原 Pi 进程、工程状态和完整请求，在执行前再次核对，仅允许使用一次。等待确认时工程可以继续编辑，改动后须由助手重新读取和选择对象。确认请求自开始核对起最多等待 90 秒，页面重连可重新读取。停止、取消、过期或进程重启会结束未执行的确认。

**验收**　对「建一个长方体」直接执行并以回执确认。对「删除 Box_1」展示目标并等待确认；拒绝后无写入。在确认前改动工程，旧确认无法提交；重新核对后可确认一次。使用生产入口重复核心场景。

## 联合验收顺序

1. 新建未命名工程，在右侧打开参数面板或使用拖拽吸附创建长方体，验证视口拾取和工程树历史。
2. 追加 STEP，用其结果体做布尔，验证记录、撤销和属性分裂规则。
3. 完成检查、测量及只读修复预览，基于全工程范围进行共形剖分。
4. 保存并另存为，验证切换提示、两个工程的名称与数据，以及日志重载。
5. 用 Web 助手完成一次直接创建、一次待确认的写入，并验证状态变化后的确认失效。

### 4. 跨弹层问题与建议优先级

| 优先级 | 发现 | 验收规则 |
|---|---|---|
| 高 | `Esc` 由面板菜单、视口菜单、操作窗和拖拽分别监听。拖拽退出已补上 `defaultPrevented` 检查，菜单处理过的按键会保留底层绘制。 | 每次 `Esc` 只关闭或取消当前有交互焦点的最上层界面。原生下拉、输入法和内嵌对话优先处理；下一次才处理下层。 |
| 高 | 操作窗的标题栏关闭按钮与 `Esc` 都调用 `setActiveOperation(null)`，没有共用草稿确认。右侧外层的隐藏按钮又是另一条路径。 | 「隐藏／最小化」保留同一窗口的草稿；「关闭／改开其他命令」有草稿时给出明确选择。应用内取消与后台任务取消使用不同入口。 |
| 高 | 普通 `OperationWindow` 的创建与关闭缺少通用焦点接管和恢复逻辑。只有命名等个别子表单单独设置焦点。 | 非模态窗打开后聚焦首个必填项或标题，仍可用键盘进入视口。阻塞式确认打开后焦点留在对话框内，默认进入取消或安全动作；关闭后返回触发控件。 |
| 高 | Body、Feature 和单个备份文件已有删除确认。工程数据与 Provider 删除还需要接入相应确认。 | 同一对象类别所有入口复用相同确认。确认时重新核对工程、对象 ID 和状态。单击取消或 `Esc` 时不向 Gateway 送出写命令。 |
| 中 | 浮窗在视口内有尺寸限制，历史预览和长表单在窄屏仍可能压缩工作区。 | 窄窗口下标题、关闭和提交始终可到达。长内容在面板内滚动，菜单不超浏览器边界。锁定焦点仅适用于真正阻塞的确认。 |
| 中 | 操作窗关闭和任务结束是不同事件。例如关闭备份面板会停止其进行中的文件读取，已发出的写入仍需从原任务核对。 | 对已提交写入保留任务 ID 和可查询状态；面板关闭时不将任务显示为成功或取消。结果未知时提供检查原任务，避免重复提交。 |

### 5. 弹窗专项验收

| 场景 | 通过条件 |

工作台声明了 30 种操作类型，其中 10 种停靠在右侧。视口 UI、编辑会话和命令日志的 60 项现有回归测试全部通过。

首次保存、另存为、工程切换及 Body／Feature 删除使用模态确认。普通操作窗打开时接收焦点，关闭时在适用情况下回到触发按钮。Chromium 回归覆盖了取消工程命名后保留底层操作窗、属性浮窗最小化后继续使用视图按钮、窄屏滚动后关闭长表单，以及工程树与历史表单的删除入口。其余跨弹层组合仍按上表验收。
