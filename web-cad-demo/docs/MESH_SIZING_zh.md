# 工程共形网格的尺寸控制

本批为独立开发候选，未更新日常服务。精确前后台版本、原生程序与实际验收见 `.artifacts/mesh-sizing-result.json`。

## 如何使用

在现有“网格剖分”面板展开“网格尺寸”。默认仍为自动；勾选自定义后填写全局目标尺寸，单位 mm。需要局部加密时，在视口、几何树或关联属性中选择 Body／Face，添加规则并填写局部目标尺寸。局部值不大于全局值，最多 16 条；同一体和某个面可各有一条，重叠处采用更细尺寸。

无论选中了哪个体或面，剖分范围仍是当前工程的全部几何，统一共形。选择仅定义加密目标，不能拆成互不共形的单体剖分。共享面及其公共边的加密也会影响相邻实体的边界，这是共形要求，并不代表规则被错误绑定到另一个 Body。

关闭工具窗口不会丢失本页未提交的尺寸草稿。刷新页面后不自动重做任务；任务记录中的“复用尺寸设置”可显式复制原设置到草稿，不提交剖分，也不重新解释旧的几何编号。未提交草稿不写入磁盘，跨页面刷新不恢复。任务设置和执行证明在后台任务中持久保存；它们目前不是随 `.cadproj` 导出的工程级网格方案库。

尺寸是生成器的目标尺度，不是所有网格边长的严格上界，也不是质量阈值。更小值可能显著增加单元数；完成后仍须查看数值质量、拓扑和共形验收。结果默认隐藏，继续使用网格面板的整体显隐和几何树中每个 Body 的单一网格按钮。

## 身份与执行边界

请求格式为 `sizing: {version: 1, globalSize, rules}`。每条规则含独立字符串 `id`、数值 `size` 和目标：`kind`、`bodyId`、32 位 Body／拓扑身份、拓扑版本；面目标另含该版本的 `cadFaceId`。数值范围为 0.000001～1000000 mm，仅接受有限数值。未知字段、字符串数值、数字身份、重复目标、超出容量等拒绝，不做宽松转换。

准备几何时，在工程串行队列中核对原身份，再通过封存的 OCCT 修复/分割来源清单解析全部目的实体。旧目标、被移除或没有可证明后继的目标报错，不忽略规则，不改用“最近的面”，也不退回自动尺寸。修复预览不生成网格，不接受尺寸参数。

原生层再次核对规则与已认证的 BREP 映射，用 `MathEval` 常量、`Restrict` 和 `Min` 尺寸场处理全部有证据的目的体和面。关闭自动边界尺寸外推，避免把局部规则无意扩散为全局策略；共享拓扑约束仍保留。相关场语义见 [Gmsh 官方尺寸场说明](https://gmsh.info/doc/texinfo/gmsh.html#Gmsh-mesh-size-fields)。请求结束或异常时移除本次字段并恢复选项，不污染后续自动剖分或文件工具。

结果记录原规则、实际 Gmsh 体/面标签与策略 `min-restrict-v1`。后台在封存及再次读取时，将证明与任务设置、体归属和 CAD 面来源交叉核对。缺项、漏体/漏面、额外标签或矛盾目标都不能作为正常结果发布。任务记录在完整服务重启后仍可读取原设置和证明，恢复结果保持隐藏。

异步任务在提交后才失败时，面板立即显示原因，保留已有结果，不自动重复提交。几何改变后复用的旧规则仍保留原身份，必须重选或删除失效规则。

## 本批验证与未完成范围

验证包括真实体网格加密、共享面的面网格加密、交叉体把同一个 CAD Body／Face 拆成多个实体后的全部后继覆盖、完整工程归属、初始隐藏、请求间选项隔离、旧身份拒绝、缺失面拒绝、执行证明校验、服务重启，以及实际页面中的选择、输入错误、草稿保留、设置复用和窄屏可读性。准确数量不取历史记录，以本批验收回执为准。

本批不实现薄层各向异性、边界层、局部质量自适应重剖或工程级持久方案库。极薄层仍可能低质量；各向同性加密不是保证解决方案。尺寸范围和规则容量不构成单元数或内存的严格上界，工业规模资源治理及重任务隔离仍要继续。任意脏几何、离散交叉、完整安装升级与整体工业化目标尚未完成。
