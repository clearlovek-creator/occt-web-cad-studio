# 工程网格方案（候选，未部署）

网格方案是工程数据，不是新的几何对象，也不放进几何树。入口位于现有“网格 → 剖分 / 修复 / 质量”面板的“工程方案”折叠区。选方案只载入设置，不开始剖分。

## 使用方式

1. 在原网格面板设置修复模式、质量阈值及可选全局/Body/Face 尺寸。
2. 输入名称，点击“保存为新方案”；一个工程最多保存 32 个方案。
3. 选择方案载入设置。修改参数后显示“临时修改”，可以“更新方案”，也可明确按临时参数剖分。“仅重命名”不替换参数。
4. 删除不增加确认弹窗，保留草稿和已生成网格；可通过工程撤销恢复。被删除/更新的当前选择必须重新核对或切到临时参数，不能继续按旧定义执行。
5. 关闭网格工具保留本页草稿；刷新页面不自动加载或执行方案。方案清单随工程持久保存，重新选择即可载入。

全部几何仍统一共形剖分；局部规则只控制加密，不缩小任务范围。结果默认不显示，原有整体与 Body 网格显示控制不变。

## 数据与一致性

- 方案使用独立 UUID、名称、定义版本、时间和严格参数结构。每次更新/改名提升定义版本；版本与完整规范化定义摘要同时约束更新、删除和执行，不能把另一个同版本定义当作原方案。
- 方案修改走现有完整工程事务、任务与历史，不增加几何修订版，但改变工程状态凭据与未保存标记。完整检查点同时绑定原生几何、类型化属性和方案库；Undo/Redo 还原整组数据，而不是分别撤销文件。
- 属性与网格方案仍是独立领域存储；聚合层只负责完整检查点。旧属性专用检查点只在内存中升级，不改写其原字节。
- 新 `.cadproj` 为 v2，携带 `projectData`（类型化属性及方案库）；v1 工程包和旧 XBF 仍可读。XBF 不携带这些工程数据。不能理解新版工程数据的旧适配器必须拒绝，不能静默丢弃方案。新旧属性输入若矛盾也明确拒绝。
- 修改要求同一次工程观察的完整状态凭据。原方案文件无法读取时拒绝视为空清单；恢复前保留可读取的异常原字节。超过安全上限/异常文件类型需要另行治理，不以覆盖解决。

## 几何引用和任务证据

局部尺寸保留准确 Body/拓扑身份、修订版和面编号。几何变化后标记“目标需重选”，不会按距离猜测或绑定同名新面。清单状态主要核对身份；保存局部面规则和实际执行仍核验真实面与来源映射。

执行已保存方案只传准确方案引用，由后台在工程队列中解析定义；不同时接受另一套临时尺寸、模式或阈值。准备导出前再次核对，期间方案变化即拒绝。导出成功后的任务持有当时的完整不可变定义，之后改名、删除、更新方案不会改变旧结果；服务重启仍核对原定义、实际参数和网格证据。

保存使用固定原请求身份。断线或矛盾回执不能当作失败后重发；界面阻止重复保存，提供“只读核对原方案任务”。读取原任务/原回执不创建任务、不修改几何，不自动覆盖当前草稿。

## 验证与边界

独立候选验证覆盖 CRUD、精确版本/摘要拒绝、撤销、工程包往返、局部引用失效、真实 OCCT/Gmsh 执行、重启恢复、丢回复仅核对原任务及 1440/640px 页面。精确候选与最终分层测试数量以 `.artifacts/mesh-strategy-result.json` 为准；没有该最终记录时本批仍在验收。

本批没有部署，日常服务与用户页面不更新。方案文件不是跨工程自动移植的领域模板；局部引用不会自动重绑定。未提交草稿不保证跨浏览器刷新保留。目标尺寸不等于硬单元数或内存预算；薄层各向异性、边界层、自适应重剖、任意脏几何/离散交叉、工业规模性能、完整重作业隔离和安装升级门禁仍未完成。
