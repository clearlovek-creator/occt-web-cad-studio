# 面边持久引用的远端拓扑证据

状态：2026-11-17，独立候选，未部署。新建的面边引用可以在近邻相同但远端结构唯一时记录额外证据，供后续改参重算使用。旧引用不会被自动改写；无法证明对应关系时仍要求重选。最终验收见 `.artifacts/topology-selector-result.json`。

## 引用恢复规则

| 引用情况 | 精确几何未变 | 几何已经改变 |
| --- | --- | --- |
| 普通 v1 引用 | 保留精确 BRep 依据 | 保留原有唯一近邻规则 |
| 没有远端证据的旧歧义引用 | 仍可编辑已明确选中的面边 | 要求重选，不补造旧依据 |
| 带远端证据的新歧义引用 | 扩展格式有效时保留精确依据 | 远端结构唯一匹配才恢复 |

例如，同一 Body 内两个面的直接邻面名称相同，但更远处的生成来源不同。新引用在用户选中其中一个面时保存这项区别。之后改变尺寸、位置或面排列，解析器仍可依据结构恢复原分支；如果原分支已消失，不能因为只剩另一个面就认为它是正确目标。

## 保存格式与兼容性

基础选择格式仍为 v1。只有近邻重复、身份完整且远端比较唯一时，才增加可选的 `remoteContext` 对象。对象有独立版本 1，比较依据为 `adjacent-face-refinement-2-v1`，保存 64 个十六进制字符的摘要和 `matchCount:1`。普通引用不新增字段。

新解析器同时读取旧引用和新扩展。未知扩展版本、错误依据、非唯一计数、缺失字段或错误摘要格式会明确拒绝。格式正确但与新几何不匹配的摘要，不能授权改参后的自动恢复。

旧内核读取本次生成的新歧义引用时，会忽略扩展，但原有“近邻不唯一”检查仍会阻止变化后的误选；原几何精确相同则保留旧行为。这是保守读取，不保证旧内核也具备新的恢复能力。工程更新仍需前后台配套验收。

## 工作额度和安全边界

捕获和解析分别使用有限的两轮邻接细化，每次调用最多 1000000 工作额度，最多尝试 100000 个 Face/Edge。内部额度可以降低，不能关闭或扩大。额度不足不保存半份证据，也不使用半份候选判断唯一性。该额度不覆盖整批特征、旧近邻索引、BRep 摘要或整个内核的资源使用。

恢复只比较生成身份和拓扑关系，不按坐标、大小、面积、旧序号或最近距离选择。重复目标、远端身份缺失或计算不足仍进入现有重选流程，工程事务保留原状态。

此次没有修改生成面的命名根，也没有扩展 `SelectionProof` 对生成身份的授权范围。扫掠、放样、壳体等生成面的身份及归档恢复仍按原证据判断；不能把“引用可恢复”理解为所有新生成面都已获得完整命名。

## 验证范围

真实 OCCT Compound 中放入两个 Solid，安排可控的重复近邻与不同远端生成身份。交换 Solid 顺序、大幅改变位置和尺寸后，新的 Face/Edge 引用解析到正确的实际子形状，解析出的边成功生成有效圆角。扩展经过 JSON 保存往返，另测旧歧义引用、低额度、原分支消失、重复当前目标、缺失身份及七类错误证据的拒绝路径。这是带合成身份的真实几何样本，不是客户 CAD 生产集。

42 项引用修复专项、1977 项完整应用测试、94 项 Python 回归、16 项几何及 3 项网格 CTest 通过。封存新内核另通过 8 项实际连续布尔、面边属性、Gmsh 传递、Undo/Redo 和保存重开检查，以及 13 项独立页面、55 项工作台和 8 项历史引用浏览器流程，页面异常为零。新扩展的核心持久化检查为 JSON 往返，不将既有工程兼容结果夸大为所有新型工程包和客户模型均已覆盖。

前端、后台 JS 和 SDK 保持原样。日常服务、默认原生文件、Box10/R222、295 份保护文件及完整 Pi 历史不更新。复杂生成身份、全部生命周期、脏离散表面重构、工业规模 GPU 和完整安装升级仍属于后续工作。
