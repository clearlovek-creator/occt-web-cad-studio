# 便携网格工程保存与恢复

便携网格把生成任务的原始证据、材料、数值结果和显示副本作为工程资产保存。任务编号和来源身份留在原命名空间内，不通过改写原始记录来冒充新工程的执行结果。目标工程使用独立资产编号，几何、工程数据、历史和资产登记纳入同一打开事务。

当前候选已接通实际保存、打开与登记任务入口。含网格资产时保存第三版工程包，没有网格资产时保持第二版；旧 XBF 和前两版压缩工程包仍兼容。候选未部署，日常运行版及现有工程保持不变。未配置资产事务集成的旧组件调用仍明确拒绝新版资产包，不静默丢弃网格。

## 二进制工程包

包含网格资产时使用第三版工程容器；旧 XBF、第一版和第二版压缩工程包继续读取。第三版不把网格嵌入多层 Base64，也不对巨大 JSON 执行嵌套解压。

| 分段 | 内容 |
| --- | --- |
| 文件标识 | `WEBCADPROJECT3` 及换行 |
| 清单长度 | 4 字节无符号小端整数 |
| 清单摘要 | 32 字节 SHA256 |
| 清单 | UTF-8 JSON，保存工程身份、修订、工程数据及二进制块引用 |
| 数据区 | 按清单次序连接的原始二进制块，每块有长度和 SHA256 |

几何、STEP 来源和网格文件按内容摘要去重。数据区没有用户指定的文件路径或偏移，读取端从有界长度计算位置，并拒绝重复块身份、缺失引用、未引用内容和额外尾部。工程与网格捕获必须使用同一工程身份和修订基线。

解码后的二进制内容引用已校验输入缓冲区，不再将所有数据复制为另一套 Buffer。调用方须持有这份输入直到暂存结束；共享或可变长度缓冲区不受支持。暂存时再次核对内容，输入发生变化不能作为有效资产使用。摘要用于证明内容一致，不代替网格质量验收。

## 网格资产清单

资产清单绑定完整工程来源，并保留每项终态任务的原始元数据和完成凭据。固定角色覆盖结果、质量、显示数据、修复 BREP 与清单、表面来源、离散来源、分区、失败诊断、MSH，以及离散派生文件集。加速查询缓存不作为不可替代的工程资产保存。

捕获要求任务不处于计算、派生准备或清理中。每份文件通过同一个已核对的文件句柄读取，结束时重新核对所有文件身份和角色清单，并执行调用方提供的工程空闲检查。符号链接、目录链接和硬链接不授予文件读取能力。已损坏或无法完整读取的必需文件会使捕获失败，不通过遗漏它们生成看似完整的工程包。

原始结果中的生成机输出标签保留为来源证据，但不用于恢复时的磁盘访问。隔离暂存只根据固定角色生成受管路径。真实验证中，原服务器的普通 MSH 被独占锁定后，暂存副本仍能独立读取。

## 暂存与独立核验

暂存目录由系统独占创建。所有块、引用和展开额度先通过检查，文件只写入该目录内的固定位置；失败清理也只作用于这个已核对的目录。

暂存后的普通网格、修复预览、表面重构、离散原始结果、派生结果和结构化失败分别复用原有验证器。原始任务的来源、材料、进程证明及完成凭据不改写。派生结果从原始材料重新推导全部预期字节摘要，不相信保存的通过标记；原始未准入结果不会仅因被打包而变成可显示网格。所有恢复摘要默认隐藏，不重新运行原生剖分。

真实候选把 6 项保留资产通过实际工程入口恢复到三个工作区，共形成 18 个独立资产编号，覆盖四类任务、离散原始与派生结果及材料冲突诊断。实际 CAD 恢复后核对完整 Body 持久身份，面边界查询连接当前属性实例；恢复出的派生文件由实际 libgmsh 重开，核对共享接口、节点和原始物理组。

## 独立资产登记组件

第二版网格清单区分目标资产编号与原始工程、原始任务编号。同一个原始任务可以作为两个独立资产存在，文件内容按摘要去重，恢复到磁盘后分别置于独立命名空间。再次保存将所有资产合并为平面清单，不逐层嵌套旧工程包。

工程登记指针绑定暂存清单和关联索引的内容证明。索引记录目标工程、资产集合编号、独立资产编号和原始任务记录；重复编号、越界路径、未知状态或不完整索引使整个登记失败。内存目录预检全部通过后才替换，磁盘指针受统一打开日志保护。已知原子写入暂存文件保持原样且不作为已发布指针使用，未知文件和异常链接仍拒绝。

显示与派生状态独立存储，不修改原始任务或完成凭据。组件支持默认隐藏、显式质量查询、派生显示文件、清理派生文件和删除单项资产。删除一个导入资产不会删除另一次导入或原服务器生成结果。请求编号不能复用于另一种操作；取消后即使校验线程已结束，也必须在发布前再次检查操作归属和取消状态。

读取复用现有有界重材料线程，等待真实线程退出后才返回或清理。普通网格历史恢复按需加载自身组件，不额外载入工程打包模块。验证缓存同时检查原始文件、派生文件、登记指针、索引与状态文件；原本不存在的状态文件后来出现也会使缓存失效。Windows 深层暂存目录使用长路径创建方式。

恢复结果可通过既有任务列表、质量、面来源、线框分块和 MSH 下载接口访问。修复预览保留认证 BREP，用户明确引用时可用于一个新剖分任务，不再次导出或修复 CAD；普通打开、再次保存和重启均不会自动剖分。完成凭据发布失败的资产可明确重新核验，新增凭据绑定原失败元数据摘要，下一次保存会保留该凭据和原始失败记录。

登记目录损坏时不返回部分清单或空历史。恢复原文件后，必须使用准确失败编号明确重试；重启恢复的显示意图始终为隐藏。前一阶段的独立组件验证记录仍保留于 `.artifacts/mesh-asset-components-native-final/result.json`。

## 大小与资源边界

网格资产默认限制为 500 项任务、9000 个内容块、384 MiB 文件总量和 16 MiB 资产清单。重复内容虽然只存一份，恢复时的逻辑展开总量仍计入额度，不能用大量重复引用绕过磁盘预算。

第三版容器清单最多 64 MiB，文件总量及逻辑展开总量继续受工程包展开额度限制，默认 512 MiB；上传和保存另受既有文件额度约束。打包、展开和资产重读使用现有有界重材料线程，工程操作持有文档串行化、网格快照锁和容量预留；网格计算、校验或清理未结束时拒绝混合保存。

统一容量清点覆盖原始网格、导入资产、登记状态及工程暂存目录，任务数量也计入导入资产和正在准入的任务。它是逻辑容量准入，不是操作系统磁盘硬配额。工业规模、整机峰值内存、任意文件写入点硬终止和断电持久性仍待验证。

## SICN 舍入边界修复

真实交叠体样本中，坐标重算的 SICN 得到 `1.0000000000000002`，原通用质量检查将它视为超范围。离散适配现在只把坐标独立重算后、超出 1 不超过 `16 × Number.EPSILON` 的值规范为 1，并记录修正数量、最大溢出与容差。原始网格、坐标、连接、材料和原生质量报告保持不变。

低质量值不会提高，真正超范围、非有限、反转和退化单元仍拒绝；通用已保存单元的范围检查没有放宽。两份保留的真实失败结果在不重剖条件下通过修复验证，输出由实际 libgmsh 重开；一个上阶段已封存的派生集合逐字节重新认证通过。未触发规范化时不增加新字段，保持原派生文件内容形状。

## 统一事务与重启恢复

打开前先校验工程包、网格资产、工程数据和 STEP 来源，再写入带原检查点证明的第三版恢复日志。日志记录旧、新网格登记指针；恢复出的实际 CAD 必须与包内完整几何身份基线一致。工程输入文件在只读来源检查前后重新核对身份，避免检查后被替换。

几何恢复与工程数据替换完成后进入禁止取消的提交阶段，发布网格指针和历史检查点，最后写入已提交标记。提交标记之前发生失败或重启，恢复旧几何检查点、旧工程数据、旧历史和旧登记；标记之后则保留已提交工程。若当前登记既不是旧指针也不是新指针，停止恢复并保留日志，不覆盖其他有效资产集合。

真实进程在历史发布后、提交标记前退出时，重启恢复原工程与原资产编号；在提交标记后退出时保留新资产集合。原生进程退出无法确认时保留恢复日志或导出暂存，不报告成功取消；取消后、提交前的失败必须完成回退后才确认已恢复。已提交工程清理上传暂存包，回退只清理本次独占目录。

格式阶段记录为 `.artifacts/mesh-archive-result.json`，独立组件阶段为 `.artifacts/mesh-asset-components-result.json`；当前实际事务、封存候选、完整回归与日常保护以 `.artifacts/mesh-project-transaction-result.json` 为准。日常工程、Box10、AI 历史、服务选择和默认原生程序不更新。
