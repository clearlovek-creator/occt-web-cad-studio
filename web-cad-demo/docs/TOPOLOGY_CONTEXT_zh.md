# 重复面/边的远端拓扑上下文匹配

状态：2026-11-17，独立内核候选，未部署。最终证据见 `.artifacts/topology-context-result.json`。这是 I4 属性完整性的进一步改进，不代表任意几何变化后的唯一命名问题已全部解决。

## 解决什么

原来的重算对应先按来源特征和生成身份分组，再比较一圈邻接关系。若两块面来自同一生成身份，连它们直接相邻面的身份也一样，即使更远处已有可靠的不同来源，原算法仍不能区分。

本次仅在原比较仍有歧义时继续查看有限层的邻接结构。可以理解为：面自己的“身份证”相同，就再比较周围几何的“身份证组合”，必要时往外查看两轮。面和边的远端结构在旧、新模型中都唯一一致，才增加一条一对一对应。不用位置、面积、尺寸、枚举顺序或最近距离选结果。

## 保守边界

- 原有直接生成身份和一圈已经证明的关系保持原行为；包括原有一对多继承策略，不改为自动选择某个后代。
- 两轮细化使用面与共享边的拓扑邻接，边再使用其端点关联面的结构；邻接身份排序，不依赖结果排列，保留不同邻接对象的重复数量。
- 任一候选缺少完整面身份、目标仍有多个不可区分分支或计算不足，不用剩余的部分证据假装唯一，仍待复核。没有增加一个“选第一个”的回退。
- 全次 MatchBodies 的可选上下文细化共用最多 1000000 工作额度，包括遍历及部分编码字节；每个 Body 最多 100000 个 Face/Edge 才尝试。内部可降低额度，不能设为 0 或提高上限。超限只放弃新的歧义消解，不取消原先可证明的普通对应。
- 这是可选细化的工作保护，不是整个旧匹配器、形状读取、名称字符串、内核堆内存或墙钟的全局硬限制。

## 兼容性

不写入新的命名根，不修改生成特征/持久选择的 v1 格式，也不改变已保存属性的原锚点。新增上下文只在同一次旧、新几何比较中计算，不能单独伪装成历史证据。面/边属性后续仍走原有版本、血缘、歧义和用户明确修复规则。

此改进用于重算后的 Body 拓扑对应，不升级旧持久特征选择器；下游特征本身若无法重算或需要重新选面，仍按原机制报告并保留工程。它不是任意结构、任意深度的图同构证明，也不保证变化后的实体都具有唯一身份。

## 验证

新增回归使用真实 OCCT Solid，但生成身份安排是可控的合成样本，不冒称来自客户生产文件：两条分支的一圈名称相同，远端底面来源不同；改变尺寸、移动到远处并交换输出槽位。旧算法在该样本无法证明对应；新算法能区分 Face 和 Edge，且不改变输入 BRep 与命名。

同一回归另验证完全对称、低额度/半途耗尽、远端身份缺失、重复当前目标和非法额度仍不误配。原有交换结果、同源对称歧义、大坐标、STEP 命名、旧精确引用和临时文档释放继续验证。两份旧算法失败日志保留，最初断言定位不足的 map::at 诊断也未覆盖。
