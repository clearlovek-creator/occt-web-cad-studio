# 局部尺寸过渡与 Netgen 后优化

2026-11-17：独立开发候选，日常服务未更新。准确候选、来源和最终验证以 `.artifacts/mesh-gradation-result.json` 为准。

## 改进路径

本次不是降低质量标准，也不是只给已有结果加警告。现有局部尺寸规则新增可选的平滑过渡宽度；网格生成后可显式调用当前 Gmsh 库内的 Netgen 四面体优化，再进行原有质量、空间、连接、共形和来源验收。

没有增加新的 AI 几何工具、独立 Netgen 服务、求解器或额外安装依赖。使用既有 Gmsh `model.mesh.optimize` 接口，参见 [Gmsh 官方 API](https://gmsh.info/doc/texinfo/gmsh.html#Namespace-gmsh_002fmodel_002fmesh)。

## 研究结果决定实现，而不是算法名字

独立实验采用 20×15×2 mm 基板及接触的 0.035 mm 薄层，minSICN 阈值 0.2，所有几何一起剖分：

| 配置 | 四面体数 | 最小质量 | 阈值以下单元 |
| --- | ---: | ---: | ---: |
| 默认剖分 | 835 | 0.01848 | 371 |
| 默认剖分后追加 Gmsh 优化 | 835 | 0.01848 | 371 |
| 默认剖分后追加 Netgen 优化 | 1206 | 0.01515 | 582 |
| 薄层 0.1 mm、全局 2 mm，无过渡 | 300150 | 约 0.05 | 18801 |
| 薄层 0.1 mm、2 mm 过渡，未追加优化 | 390353 | 约 0.0000483 | 14 |
| 同一过渡后追加 Netgen | 387941 | 0.26144 | 0 |

默认优化和节点重定位对本样本没有改善；单独 Netgen 甚至降低最差质量。过渡显著减少粗细交界的问题数，但未优化时最差单元仍可能退步。因此两项均为可选参数，不能把“执行过优化”当作验收通过。

上表是直接使用 Gmsh/现有尺寸场的研究对照，不是完整产品吞吐量测试。正式公开工程接口另行验证同样几何、配置和属性：约 38.8 万四面体，最小质量约 0.26144、阈值以下为零、严格验收通过，Body/Face 归属、共享界面与面属性均保留。不同构造/遍历路径可能产生少量单元数量差异，测试不硬编码某个准确单元数。

0.15 mm、0.2 mm 的较粗局部配置在研究中仍有不合格单元；并非随意填一个较小尺寸就能达到阈值。这个反例和其他失败/退步材料保留。

## 如何使用

1. 在现有网格面板启用自定义尺寸，添加准确选中的 Body 或 Face 局部规则。
2. 填写局部目标尺寸。平滑过渡宽度可留空，留空完全保持原来的局部规则；填写正数后，在来源面附近从局部尺寸逐渐恢复全局尺寸。
3. 按需要勾选“生成后执行 Netgen 优化”。普通新设置使用 Gmsh API 的迭代参数 5；载入已有方案保留其准确参数（支持 1～5），不会偷偷替换为默认值。
4. 需要质量门槛时同时启用严格验收。结果区展示实际优化前后最小质量、问题数及四面体数量；前后单元编号可能变化，不能按旧单元 ID 绑定新结果。

质量阈值仍是验收和前后统计标准，不被当作优化器必然达到的内部目标；不能因为填了 0.2 就承诺最终最小质量一定超过 0.2。

过渡会影响相邻 Body，也可能加密附近不相交的几何。它是来源面的采样距离场，不是按包围盒估算实体厚度，不承诺严格各向异性或精确距离误差。局部尺寸仍受整个工程共同共形约束，共享面取更细规则。

## 实现与一致性

- 请求局部规则的 `transitionDistance` 使用模型毫米，严格正数及既有长度上限；通过准确来源解析全部后继面，不按距离猜测归属。距离字段只决定尺寸，不决定几何所有者。
- 在已有 `Restrict` 字段外叠加 `Distance`（采样参数 100）和线性 `Threshold`，最终取所有规则的最小值。缺少可证明来源面拒绝，不忽略请求。结束或异常清理本次字段，恢复原选项。
- `optimization: {version:1, method:'netgen', iterations:1..5}` 为显式可选设置。优化在写出 MSH、质量索引、显示线框之前执行，全部输出对应优化后的同一网格。
- 原生报告保存实际前后质量；后台核对请求、迭代设置和最终报告的一致性，封存和重新读取均核对。旧内核忽略参数、缺少报告或返回矛盾报告时拒绝，不悄悄发布未优化结果。
- 过渡与优化随工程网格方案、工程包和任务保存；旧方案没有这些字段时，结构与定义摘要保持不变。草稿关闭再打开保留，刷新后须显式载入方案或复用原尺寸，不自动重剖。
- 原有进程内存限制、取消、超时和实际退出后才发布的边界继续生效。Gmsh 未编入可用 Netgen 或优化失败会明确失败，不回退为另一算法冒充成功。

## 仍未完成的边界

这条路径不是薄层各向异性/边界层网格，也不是自动自适应重剖。达到 0.2 的本例需要从几百增加至约 38.8 万单元，CPU、内存、文件及完整验收成本都显著增加。端到端工程验证比原生剖分更慢，尚未取得工业规模吞吐量或整机总资源资格。

前置数值摘要由原生报告提供，不是另存一套优化前网格的独立复核。最终网格仍由原有索引、拓扑与空间检查独立验收。当前样本成功不证明任意脏几何、复杂多域或其他厚度均适用；优化后可能仍不合格甚至更差，必须查看结果，不能自动降低阈值。

界面保持原工作台配色、字体、40px 控件和紧凑规则布局，只增加必要设置与前后指标，不增加弹窗、不保存界面规范文件。日常 R222 与 Box10、配置、默认程序和页面保持不变。
