# 组件来源与许可证据清单

本工具为固定运行候选生成可追溯材料，不进行法律判断，也不签发正式发布许可。它不会更改候选、日常服务、工程或 AI 历史。

## 首批结果（历史，不改写）

2026-11-17 的报告位于 `.artifacts/component-inventory-final`，对应 `bundle-path-guards-result.json` 中的原工作台候选。7,446 个文件均进入逐文件账本；185 个组件包括 52 个 npm/运行器包、Node、98 个本机原生包、5 个项目原生程序以及 29 个尚未映射的原生文件。117 份许可/声明文本按内容摘要去重保存，合计 1,075,891 字节。

227 个原生文件中，193 个与当前本机安装包列出的文件长度和 SHA256 精确一致。29 个未映射文件均来自 geometry 配置的 OCCT DLL；不因名称像 OCCT 就自动套用某版源码或许可。5 个项目程序也仍缺完整的构建来源/发布许可签证。同名 DLL 按运行配置分别记录。

许可字符串仅是元数据声明。13 个包自身目录未发现许可文本，不等于已确认无许可或不合规；可能存在上层许可，尚待人工确认。98 个已匹配原生包的许可未在运行候选内交付，其中 18 个在本机数据库中也未找到独立许可文本。外部副本只是报告证据，不补写原候选。

## 使用与输出

```powershell
node scripts/acquire-cyclonedx-schema.mjs --output .artifacts/my-schema-input
node scripts/inventory-workbench-components.mjs --bundle <准确工作台版本目录> --schema-dir .artifacts/my-schema-input --msys-root C:/msys64 --output .artifacts/my-component-report
```

结构文件必须与代码中固定的三个官方文件摘要一致；内容变化需要明确审查，不能只重写本地摘要冒充通过。生成器不覆盖输出，拒绝输出嵌入输入或受保护目录。输入核对结束后才建立输出；写出中途 I/O 故障可能留下部分报告，需保留检查。

不提供 MSYS 根时仍可生成，但原生来源保持未映射，不按文件名猜包。只读取有界普通文件，拒绝链接/联接、硬链接、越界路径和读中变化，并复核包数据库。此层不是操作系统目录锁或高权限恶意并发竞态认证。

- `inventory.json`：组件、精确文件账本、来源/许可摘要和缺口。
- `bom.cdx.json`：CycloneDX 1.6 清单，组成明确为 `incomplete`，不伪造依赖图。
- `licenses/<SHA256>.txt`：内容寻址的实际声明字节。
- `result.json`、`SUMMARY_zh.md`：材料摘要、计数、校验凭据和中文概览。

Ajv 6 适配器仅移除经过形状检查的 33 个枚举说明标注，保留真实 enum；`deprecated` 按布尔说明标注处理。未知关键字/格式仍拒绝。保守格式子集限 ASCII IRI 引用和 ASCII 邮箱本地部分（域名可经 IDNA），其余格式使用完整模式。这不是通用国际化校验服务。官方 draft-07 的 `$ref` 兄弟说明按该草案处理，提示没有隐藏。结构通过不代表组成完整或可发布。
