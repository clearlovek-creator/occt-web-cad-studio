# 视口静止时停止绘制

状态：2026-11-17，独立候选，未更新日常服务。最终回执为 `.artifacts/viewport-demand-result.json`；本项属于 I6 性能改进，不代表整个工业化目标完成。

## 行为

主视口和历史输入预览不再维持永久动画循环。模型、选择/高亮、修复预览、绘制草稿、网格分块、网格/几何显隐、构造网格、布局尺寸或相机发生变化时，请求下一帧；同一帧内的多次更新合并。相机阻尼仍逐帧运行，稳定后停止。

页面隐藏或 WebGL 上下文丢失时取消待执行帧并保留更新意图。页面恢复时补绘；主视口按原有上下文恢复流程重建场景，工程不重做。卸载先停止调度，再释放场景和显卡资源，旧回调不能消费新视口的请求。

调度器区分“有待执行更新”“暂停”“已释放”，不用 `0` 充当没有帧的标记。绘制期间再次请求不会丢失；异常会传播，并取消该次排队的后续帧，不形成持续报错循环。

## 接入边界

- 模型渲染出口及提前返回通过 `finally` 请求刷新，包含不通知 React 的按需几何载入。
- 网格线每个异步分块的已有 `onUpdate` 请求刷新，不依赖进度文案恰好改变；隐藏、失败或取消同样更新显示。
- 选择和覆盖层增删、构造网格、拖拽底面/高度及取消均显式请求刷新；不采用“任意 React 更新就重绘”的兜底，因此助手文字流不必持续唤醒静态视口。
- OrbitControls 的 change 唤醒视口，update 的实际变化维持阻尼。身体/视锥诊断在场景变化、相机稳定或间隔达到时更新，不新增后台定时轮询。
- 历史输入预览的选择、环高亮、旋转和缩放也使用同一调度器。临时视图原有上下文丢失提示保持，不擅自增加重算或恢复提交。

## 证据与检查口径

新增 10 项调度回归，覆盖静止、合并、阻尼、绘制期间请求、隐藏/恢复、迟到回调、卸载及异常。完整 1977 项应用测试及 94 项 Python 回归通过；类型检查通过。主页面保留 8 条既有 lint 警告，新增模块与历史预览无新增警告。

浏览器注入只读计数包装，统计实际 WebGL draw 调用，而不是只信任应用自己的帧计数。旧版真实 Box 静止约 702 ms 内仍有 588 次 draw 调用；候选在静止、标准视图、轴测阻尼停止、显隐、树选择、面板缩放及真实上下文恢复后的各约 350 ms 观察窗内均为 0。观察窗长度不同，未据此计算百分比或功耗收益。

使用 Chrome 软件渲染、一个实际 OCCT Box；不是硬件 GPU 功耗或工业大装配的认证。操作时的绘制和 GPU 上传成本仍在，复杂模型拾取、渲染批次与整体资源预算仍需继续。

封存前后台通过 13 项空宿主/按需绘制检查、55 项完整工作台及 8 项历史引用修复流程，覆盖全部 14 种拖拽、模型创建、异步网格、面/边/属性高亮及历史输入。历史输入在真实选面像素核验后另核对整个页面 WebGL 静止。原版另通过 7 项对照/空宿主检查。准确候选身份以回执及各 `workflow.log` 为准，不沿用旧批数量。

验收中保留了以下准备问题的原始失败记录：

1. 旧空宿主脚本在页面初始化后由外部创建 Box，依赖初次读取恰好包含它，不能证明 SSE 同步。现先创建实际模型，再验证同源初次读取；页面内操作另行测试，不声称解决外部修改的实时同步。
2. 临时网页来源与额外临时后台需要准确配对；修正测试环境的 WEB_ORIGIN，没有放宽产品的来源保护。
3. 多标签页旧检查强行点击已被正确禁用的过期/已删除草稿保存按钮。现接受前置禁止或请求拒绝两种安全路径，仍核对草稿保留、最新值不被覆盖、显式重载及删除后不复活。
4. 材料撤销旧检查以“操作窗口已关闭”作为等待结束，可能在撤销实际提交前读取。现等待准确的 document.undo 回执，再比较完整材料，不降低还原断言。
5. 布局检查曾打开真实本地 Pi 会话，关闭面板不等于会话已空闲。文件操作检查前只停止该隔离夹具的受管会话，核对真实 activity 为 idle 后才新建/打开；没有绕过工作区保护，也不删除历史。
