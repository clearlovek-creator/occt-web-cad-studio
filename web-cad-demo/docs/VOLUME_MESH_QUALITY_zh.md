# 共形四面体的质量优化与退步保护

四面体算法已增加坐标独立质量计算、三种显式优化方式、逐连通体质量规则和优化退步保护，现由[正式组件](DISCRETE_TETRA_WORKER_zh.md)与实验入口共用。两个交叠体及三体交叠样本的低质量单元已能明显改善；旋转相交样本仍未满足本次 0.2 的检查规则。功能尚未接入工程网格任务或日常服务，不能据此宣称任意工业脏几何已验收。

## 独立计算单元质量

对每个一阶四面体，从节点坐标构造其相对于正四面体的线性变换，计算带符号的逆 Frobenius 条件数 SICN。正四面体为 1，退化单元趋近 0，方向反转为负。先归一化边向量，再计算矩阵及余子式，避免单纯缩放导致上溢或下溢。

原生程序逐单元对照坐标计算值与 Gmsh 的 `minSICN`，差异超过 2e-10 即拒绝。独立 JavaScript 检查器再次从输出坐标计算，不接受仅修改质量数组或最小值摘要的结果。解析测试覆盖正四面体、方向反转、平面退化及 1e-140 至 1e140 的尺度。Gmsh 质量 API 的指标定义见[官方接口说明](https://gmsh.info/doc/texinfo/#gmsh_002fmodel_002fmesh_002fgetElementQualities)。

## 优化与公共边界保护

支持显式选择 Gmsh 默认四面体优化、Netgen 或 Relocate3D，迭代次数限 1 至 5。未指定时不调用优化器；不将任一种方法描述为总能提高质量。各方法均只针对体实体执行，不开启强制离散曲面优化。方法语义见[官方优化接口](https://gmsh.info/doc/texinfo/#gmsh_002fmodel_002fmesh_002foptimize)。

优化前保存所有来源曲面的有向三角面、实际节点编号和坐标。优化后要求逐项完全一致；边界节点移动、反向或换成坐标相同的新节点均拒绝。最终网格继续核对公共界面共用节点、体单元面连通、来源三角面内覆盖、每个连通体及并集体积守恒，不因优化而放宽检查。

默认采用不退步规则。只要某个连通体或全局的最小 SICN 下降超过 2e-10，或者低质量单元比例增加超过 1e-12，就保留优化前的网格。全局另行比较，防止各体域的单元数量变化掩盖总体退步。恢复仅使用该进程的有界内存快照，不写临时网格文件、不重新剖分；恢复后精确比较所有实体分类、节点编号、坐标、参数坐标、单元编号和连接关系，并核对原质量摘要。恢复失败不能返回成功。

结果区分 `before`、`candidate` 和最终 `after`，并给出退步的连通体和 `retained-original` 或 `optimized` 状态。显式 `diagnostic` 接受方式可用于比较退步的候选，不是默认路径，也不代表工程准入。

## 显式质量规则

`quality` 使用版本化对象，指定 `diagnostic` 或 `strict`、SICN 门限和允许的低质量单元比例。规则同时检查每个实际连通体和全局，不能用大体积优质区域稀释小体域的问题。未指定时按 0.2、允许比例 0 生成诊断，不自动拒绝。

严格模式不合格时返回 `MESH_QUALITY_REJECTED` 和质量、优化概要，进程以非零状态结束，不返回节点或单元数组。诊断模式可以返回不合格的研究网格，但明确标记 `meetsRequestedQuality: false`。即使规则通过，`normalMeshAdmitted` 仍为 false：材料冲突、正式来源准入和任务生命周期尚未接入。

## 当前验证结果

91 项专项检查通过，包含 15 个几何样本分别执行三种优化、真实退步恢复、显式诊断、严格通过及拒绝、优化后再次严格验收、非法参数和 8 项内存篡改反例。另有 1 项新原生综合测试与既有 20 项原生回归通过。完整产品的 2168 项 Node、94 项 Python 和 87 项页面基线按未变化的运行源码及前端输入复用，本轮没有重跑全套页面。

以下为固定构建的一次记录。优化前后在同一次网格生成中比较，不用不同运行的随机细节推断改善。

| 样本与方法 | 优化前最小 SICN | 最终最小 SICN | 优化前低于 0.2 | 最终低于 0.2 |
| --- | ---: | ---: | ---: | ---: |
| 实际 CAD 交叠快照与 Gmsh | 0.04359 | 0.31590 | 12 | 0 |
| 三体交叠与 Netgen | 0.01806 | 0.23863 | 48 | 0 |
| 旋转相交与 Netgen | 0.02930 | 0.07618 | 85 | 36 |

最终运行实际触发了三组退步恢复，涉及分离体、面接触及包含空腔；前批运行触发的样本不同，均保留原记录。不承诺优化每次产生完全相同的节点数或候选退步集合。坐标独立指标与引擎指标的最大差异约为 7.89e-15。

构建、测试、原始回复和保护摘要汇总在 `.artifacts/volume-quality-result.json`。日常工程保持 R222、Box10、295 份保护文件和完整 Pi 会话；服务没有重启或刷新。下一步将合格的核心接入已有受控任务，并继续处理旋转与薄小特征的质量限制、材料冲突和工业样本规模。开源许可与完整对应源码的分发条件继续沿用[体网格原型边界](VOLUME_TETRA_RESEARCH_zh.md)。
