# Body 外观编辑器的可读性与保存状态

状态：2026-11-17，独立前端候选，未部署。几何设置现在用可见色块和 HEX 值表达颜色，用滑块和精确百分比表达不透明度；保存反馈与当前草稿一致，无更改不会提交。准确版本和验收证据见 `.artifacts/appearance-editor-result.json`。

## 控件与布局

旧取色器宽 50px，但左右留白合计 44px，实际可用色块宽度约 6px，且继承了旧深色背景。新取色器为 44×40px、4px 留白，沿用原生颜色选择与键盘语义；旁边提供可复制、可直接输入的六位 HEX 值，忽略大小写及可选的井号差异，不把非法颜色默认为黑色。

不透明度明确使用百分比，范围仍为 5%–100%，数值越小越透明。数字框支持小数，滑块不把 42.5% 之类的值强行取整；方向键调整 5%，Shift 加方向键调整 1%，Home 和 End 到达两个端点。输入无效时保留原文字并说明原因，禁止提交，而不是自动截断。

布局沿用浅灰工程工作台、工程蓝焦点、4px 间距体系和现有明暗层级。字段值 13px、标签与辅助信息 12px，控件至少 40px 高。Body ID 与材料分组说明提供编辑上下文；色块、HEX、百分比和明确状态承担信息，不增加装饰卡片或确认弹窗。选中几何的高亮会覆盖外观颜色，表单保留说明，避免误认为取色无效。

## 保存规则

| 状态 | 行为 |
| --- | --- |
| 尚无更改 | 禁用保存，Enter 不创建新修订 |
| 有未保存的更改 | 仅提交真正改变的名称、材料、颜色或不透明度 |
| 保存中 | 锁定当前字段，额外提交不会重复发送 |
| 已保存 | 仅在自身提交得到成功返回后显示；继续修改立即移除旧成功提示 |
| 保存未获确认 | 保留草稿与错误提示，不自动重发，也不凭失败返回宣称模型一定未修改 |
| 工程已变化 | 沿用现有编辑会话校验，保留旧草稿并阻止提交；由用户明确重新载入 |

“重置更改”只恢复本表单最后确认的值，不发送建模命令。只改名称时不重新提交原有不透明度，避免百分比格式化改变原生双精度值。名称长度按原生 UTF-8 字节限制校验。保存后不会把焦点从用户已转到的其他可见控件抢回。

## 验证范围

旧界面保留四项失败证据：色块过窄、无更改也可保存、缺少精确百分比输入、修改后残留成功提示。新增 20 项草稿测试覆盖 HEX、精度、百分比、名称限制、最小补丁和键盘规则。最终 2085 项应用及 94 项 Python、80 项专项、15 项外观及实际材质页面流程、76 项工作台与历史引用兼容流程通过，页面异常为零。

页面同时检查实际 WebGL 不透明度参数、原生工程重开、Undo/Redo、受控失败、回复延迟、额外提交、焦点和旧草稿校验。三个宽度为 1440、640、420px；检查控件范围、焦点边框和保存按钮滚动可达性。默认及错误状态共 40 份文字对比度记录，最低 5.58:1，高于检查采用的 4.5:1。已复核对应截图，但这不是整个产品的无障碍认证或真实 GPU 验收。

类型检查通过，新增外观组件及相关检查文件无 lint 警告；大工作台文件保留与历史记录逐项一致的 8 项 Hook 警告。初次类型衔接、两项旧源码位置断言及窄屏中隐藏树按钮的焦点测试准备错误均留存，修正后保留原有行为断言，没有借此修改产品命令逻辑。

后台、原生内核与 Pi SDK 复用上一批已认证版本，本轮没有重跑或冒称新增原生 CTest。日常 R222、Box10、295 份保护文件、完整 Pi 历史和服务不更新；不保存新的界面规范。其他页面的控件一致性、复杂拓扑、工业脏几何、总资源治理与安装升级仍需继续。
