# 共享体域的共形四面体原型

算法已使用 CGAL 连通体边界和 Gmsh 4.15.2 生成真实一阶四面体，现进入[正式四面体组件](DISCRETE_TETRA_WORKER_zh.md)，实验入口复用同一核心。相邻体域共用界面节点编号和三角面，不是两套坐标接近的独立网格。空腔、嵌套空腔、旋转交叠及同一归属区域内多个连通体均已验证。后续已补充[独立质量计算、显式优化与退步保护](VOLUME_MESH_QUALITY_zh.md)；部分样本仍不满足质量规则，工程持久任务尚未接入，结果不进入普通工程网格，日常服务没有更新。

## 体域和来源

[体域分区](VOLUME_DOMAIN_RESEARCH_zh.md)输出每个连通体的外壳、空腔壳、区域编号和原始 Solid 集合。每片公共三角面只有一个全局身份，两个相邻体域反向引用它。Gmsh 为这些原始三角面分别建立离散曲面实体，建立公共拓扑与离散参数化，再用各体域的有向曲面环创建体。

Gmsh 同时重划公共表面和体网格。同一个公共曲面实体只划分一次，结果被两侧体网格复用。输出边界保留原始三角面编号与来源，再映射到 Body、Face、Solid；体单元按实际连通体分组。交叠体域保留多个源 Solid，不自动决定材料优先级。

最初仅划分空实体的设置会保留旧表面，单个 Box 改尺寸参数后仍只有 8 个节点和 6 个四面体。当前改为共同重划表面和体，使用显式常量尺寸回调。在边长为 2 的受控 Box 上，尺寸 0.4 得到 267 节点和 863 单元，尺寸 1.6 得到 79 节点和 189 单元。更小尺寸不保证更好质量，原无效尺寸设置的结果保留用于对照。

## 独立核验

连通体阶段 29 组检查、实际四面体阶段 28 组检查全部通过。四面体检查器不只读取引擎成功标志，还核对以下关系：

- 所有四面体有四个不同的有效节点，方向和体积为正，全局无重复单元；每个连通体的单元通过面邻接连通。
- 内部面恰好被两个单元反向引用。每片实际边界面均有来源；共享界面在两侧使用完全相同的节点编号，并且方向相反。
- 重划边界顶点位于原三角面内，支持平面偏差和面积覆盖满足检查门限，不用最近点猜来源。
- 单体、区域及并集体积守恒，原始 Body、Face、Solid 来源保持。体积基准是修复后的离散输入，不是 CAD 曲面的严格精度认证。
- Gmsh 返回的 SICN 单元质量必须有限且大于零，数量、最小值与结果摘要一致。低于 0.2 的单元另行统计；该阈值目前是诊断值，不是工业准入规则。

坐标完全相同但节点编号断开的假界面、缺失单元、反向单元、错误 Body 来源及伪造最小质量摘要均被检查器拒绝。原生进程另拒绝未单独导出的体域、错误共享方向、缺失壳面、非法尺寸和关闭内存保护。

## 质量结果

下表为本次固定构建与检查记录中的结果，不承诺每次生成单元数完全一致。除尺寸对照外采用 0.8 的统一目标尺寸，未启用优化器。

| 样本 | 连通体 | 四面体 | 共用界面三角面 | 最小 SICN | 低于 0.2 的单元 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 两个交叠 Box | 3 | 1195 | 196 | 0.04330 | 11 |
| 实际 CAD 导出的交叠 Box 快照 | 3 | 1185 | 196 | 0.04359 | 13 |
| 嵌套空腔 | 3 | 1686 | 316 | 0.20396 | 0 |
| 三个交叠 Box | 5 | 2794 | 398 | 0.01806 | 49 |
| 旋转相交 | 3 | 1412 | 288 | 0.02794 | 94 |

这些未优化基线说明共形与归属链路已经跑通，但不能作为网格质量合格结论。后续优化能改善部分样本，也会使个别体域退步；当前已增加逐连通体规则和精确恢复保护，实际结果见[质量优化](VOLUME_MESH_QUALITY_zh.md)。

## 运行边界

原型为独立的一次性进程，不加载用户 Gmsh 配置，不启用 GUI；使用固定 4.15.2 头文件和导入库，运行目录封存 155 个实际 PE 文件，不借用继承的 PATH。请求只接受体域结果和目标尺寸，不接受文件路径。

| 项目 | 限制 |
| --- | --- |
| 输入点和边界三角面 | 60000 点和 20000 面 |
| 连通体 | 128 个 |
| 输出点、四面体、边界三角面 | 100000 点、200000 单元、200000 面 |
| 请求和回复 | 8 MiB 和 64 MiB |
| Windows 提交内存 | 默认 2 GiB，不可关闭 |
| 检查脚本时限 | 120 秒，停止专属进程后等待实际退出 |

这些是隔离原型预算，不是整机并发资源承诺。正式任务握手、取消恢复、保存重开、材料冲突、Sheet 约束、工业脏几何和大规模模型仍需开发。当前 `normalMeshAdmitted`、`materialPriorityAssigned` 和 `publicDistributionQualified` 均为 false。
