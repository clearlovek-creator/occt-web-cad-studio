# 网格质量验收规则

2026-11-17：独立开发候选，日常服务未更新。准确版本和最终测试记录见 `.artifacts/mesh-quality-policy-result.json`。

## 为什么需要独立规则

“剖分完成”“全部几何共形”“归属正确”“达到质量阈值”是不同结论。极薄层可以生成共形四面体，但仍有很差的 minSICN 单元。此前阈值以下单元只产生警告，仍允许正常显示和下载；这不适合所有工程的验收要求。

在现有质量阈值下增加“低于阈值时阻止验收”开关：

- 不勾选：沿用历史警告行为，低质量网格仍可使用，但需复核。
- 勾选：严格验收。任何低于阈值、且不是反转/退化/无效单元的低质量四面体都会阻止正常使用。结果保留为诊断材料，允许查询和定位问题单元、明确下载诊断文件，不允许正常显示或作为合格网格下载。
- 反转、退化、无效数据、漏体、来源矛盾等已有错误，在两种模式下都不放行。严格模式不是允许忽略这些问题的总开关。
- 阈值使用严格小于关系；等于阈值不是低于阈值。设置为 0 不能豁免反转/退化等错误。

任务仍可能显示“已完成”，表示计算及文件写入结束；结果的“验收未通过 · 仅供诊断”才是使用限制。没有把质量不达标伪装成网格进程崩溃。

## 规则归属与恢复

临时规则由当前工程工作区维护，关闭再打开网格工具不丢失；刷新后恢复为临时默认，必须显式载入命名方案。工程网格方案可保存严格规则，随工程包保存/打开和历史撤销恢复。

每个新任务保存准确的 `qualityPolicy`（`warning` / `strict`）与 `qualityThreshold`。网格结果由后台封存同一验收设置；再次读取时核对任务和封存设置，并按已核验单元数据重新验收。不信任原结果里声明的 `usable` 标志，也不信任当前页面草稿。

结果区显示“本次验收”规则。修改下一次任务的开关或阈值，不改变旧结果的规则；质量报告的筛选阈值仅查询已有数据，不影响验收，也不会自动重剖。规则改变要通过明确的新任务执行。

命名方案的准确定义摘要包含严格规则。旧方案省略规则仍按警告模式读取，定义摘要保持不变；不能在引用方案时同时发送临时规则覆盖它。AI 的原有方案工具使用同一结构定义，没有增加新的建模工具。

下载响应增加 `X-CAD-Mesh-Quality-Policy` 和 `X-CAD-Mesh-Quality-Threshold`，诊断文件仍使用 `diagnostic-` 文件名前缀。

## 验证范围与限制

真实测试采用 20×15×2 mm 基板及接触的 0.035 mm 薄层，全部几何统一共形剖分：0.2 阈值的严格任务被限制为诊断，警告任务仍可使用。没有反转和退化来代替低质量条件；独立验证了确有低于阈值的正常单元。

测试包含任务重启、工程包中的方案恢复、旧摘要兼容、拒绝元数据降级、流式和内存读取路径、筛选阈值不能放宽原验收、原几何保持及显式后续任务。浏览器覆盖规则保存、关闭恢复、真实薄层结果、问题单元实际像素高亮、刷新后载入准确方案、桌面/640px 与键盘焦点。

本项只使质量要求成为可执行的验收门槛，**不改善四面体本身，也不等于薄层各向异性、边界层、自适应优化或全行业网格规范已经实现**。质量阈值由用户按自己的前处理用途选择；系统不为仿真求解效果背书。

界面复用现有工作台配色、字体和控件样式，不新建弹窗、不保存界面规范文件。R222、Box10、日常服务和默认原生程序保持不变。
