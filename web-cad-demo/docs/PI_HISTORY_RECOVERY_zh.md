# Pi 历史身份与显式归属恢复

本说明对应 2026-11-17 的开发候选。用户要求暂不更新日常服务；没有扫描认领日常旧会话或迁移历史。精确源码、前后台候选与实际验证见 `.artifacts/pi-history-ownership-result.json`。

后续候选补齐异常本地恢复记录的保留、修复与导出，并修正已核对会话的连接目标竞态，见 `.artifacts/pi-local-recovery-result.json`。后台仍复用 `.artifacts/workspace-read-result.json` 的封存版本，未修改原生 Pi、SDK、后台归属协议或日常服务。以下历史批次的测试数量不作为新候选资格。

## 新工程不能借用旧会话身份

没有几何数据不等于全新身份。专用新建及工程文件打开在取得来源/目标互斥后，再只读核对目标的 Pi 材料：

- `webcad-目标ID` 目录即使为空，也不复用。
- 其他名称的会话若已有可信归属绑定到目标，也不复用。
- Windows 下按文件系统大小写规则核对碰撞；损坏/共享归属文件、未知目录、扫描超预算或清单变化不能被当作“没有旧历史”。
- 核对只读归属元数据，不读无关会话正文，不自动认领无归属旧会话。最多 2048 个会话目录，每个归属记录沿用 8 KiB 限制；扫描分段让出执行，不是无界后台任务。

注册之后、排队期间被 Pi 会话占用的目标也会在执行时拒绝。拒绝在目标原生几何命令之前发生，原会话、配置和源工程保留，任务返回未执行证明。它复用原任务/事务引擎，没有第二个创建队列。

## 旧会话恢复入口

原生连接收到 `PI_SESSION_OWNER_REQUIRED` 后，助手内显示“旧会话需要核对工程归属”，不再只是无法连接的错误。布局沿用浅色 CAD 面板、蓝色操作与 40px 按钮，无新弹窗。

1. 点击“只读核对历史”：显示当前工程、原会话、文件数、字节数、有限原对话与折叠摘要。不启动 Pi 或大模型，不写历史或归属。
2. 用户核对后勾选“这份原历史属于当前工程”，再点击“确认归属并连接”。无法解析或没有可读片段时，页面不提供确认能力，保留材料供离线核对。
3. 服务按原文件字节、文件身份、目录清单、工程与会话摘要重新核对，只追加独立的归属记录，不改写原生 JSONL。内容变化则拒绝，需要重新查看和勾选。
4. 确认回复丢失时保留本地请求身份；刷新后先进入核对，不先启动 Pi。只有 GET 读到相同工程、会话和原摘要的已绑定记录才解除待核对，随后由用户明确连接。GET 仍为 legacy 不证明原 POST 未执行，不能自动重提。

本地恢复身份按服务 API 根、工程和会话隔离，保存并读回失败则不发送确认。坏恢复记录不自动删除或覆盖。明确的服务端“写入前拒绝”可以解除该未执行请求；进入归属文件写入后的失败标记 unknown，不能谎称没开始。

## 异常本地标记的安全恢复

助手工具栏“恢复记录”进入同一个内嵌面板，不增加确认弹窗。此入口也能在重新载入后查看并导出本地备份，不是工程包或原生对话历史管理器。

工具栏保持两行：第一行给模型（以及可用时的思考级别），第二行为压缩、历史、恢复记录、新会话和设置。按钮与选择器至少 40px 命中区，复用 CAD 令牌；不会把模型名称挤成几个字符。范围限定于助手，不借此改写整个工作台的全局控件层级。

1. 原恢复标记无法解析、身份不匹配或超出原 1 Ki 字符限制时，保持原值并阻止原生启动。只读核对不会清除它。
2. 只有后台已绑定当前工程/会话，用户又明确勾选时，才允许“备份原记录并修复标记”。legacy、absent、empty、外国身份、畸形证明不能作为清理依据。格式有效但结果尚未确认的原请求仍只读找回，不能通过此入口当坏记录放弃。
3. 修复取得同命名空间的浏览器 Web Lock，再 GET 复验已查看的 ownerToken、创建时间、采用方式与历史摘要。界面已关闭、凭据变化、其他页面正在处理或原值变化，均不继续清除。
4. 完整原值与对应后台归属凭据保存到独立本地备份，验证原文摘要、整个备份目录及写后读回；之后才移除原异常标记，并读回确认。备份失败、配额不足、记录更替或移除未确认时，保留证据、阻止连接；已保存备份可显式重读，重复修复不制造副本。
5. 修复本身只有后台 GET 与本地存储操作，不提交归属、不启动 Pi、不修改几何或 JSONL。修复成功后仍需明确点击连接。

预算：每份原值最多 65536 个 UTF-16 码元，每个服务/工程/会话最多 8 份、目录最多 512 Ki 码元，不遍历其他浏览器存储或自动删除旧备份。摘要对原字符串的 JSON 编码计算，以保留未配对代理项，不把 TextEncoder 的替换字符当成原值。损坏/陌生/重复/摘要不一致的备份均不覆盖；超过预算或浏览器没有 Web Locks 时保留材料并说明原因，需要离线维护。

本地备份可下载为 JSON，保留准确原值、来源键、服务/工程/会话及核对凭据；原文默认不铺到对话中。此文件可能包含本地数据，应妥善保存。浏览器读回不等于操作系统落盘、断电认证或用户已保存下载文件，清理站点数据也会丢失本地备份；重要材料应实际导出。没有新增不明确的自动恢复、清空缓存或强行改绑入口。

## 已核对连接的身份固定

真实浏览器反例证明：旧代码在点击连接后重新读取共享会话偏好，另一标签页可把目标改成同工程的另一空会话。本候选将显式核对的工程/会话固定到本次连接，先保存并读回，再交给连接层；不在异步重连时重选共享偏好。“恢复记录”查看实际连接身份，而非将后来改过的偏好当作当前会话。原生返回的准确身份由只读、不可变绑定提供。

这不等于所有标签页、账户或服务实例都已具有完整命名空间；共享会话偏好与底层服务配对仍需后续整理。已确认的归属仍不可被页面改绑，修复不会重发提示或模型命令。

## 预览的范围

普通 `GET /api/pi/session-ownership/:session?documentId=:id` 仍只返回元数据，不含消息。仅显式增加 `preview=1` 才返回有限片段，其他查询和不可信来源被拒绝。

完整原字节仍按既有 256 文件/256 MiB 总量、64 MiB 单文件预算核对摘要。预览最多解析 10000 行，单行 64 Ki 字符，保留 12 条用户/助手文本，每条最多 1000 字符；工具 JSON、思考内容、图片和全部历史不会摊开到界面。超限与遗漏明确说明，片段不是完整历史的替代物，也不是自动判断工程归属的模型工具。

## 真实原生上下文恢复

实际测试发现：Pi 的 `--continue` 会按启动 cwd 筛选历史。新旧候选运行目录不同，即使会话归属正确，也可能启动空上下文。

当前启动在已核实归属的私有会话目录内，选择最新有效原生 session 头文件，传递准确的私有 `--session` 文件路径，不再用新版本 cwd 猜测原历史。文件读取数量、单文件/头扫描和文件身份有界，拒绝共享、变化或无法核对的历史，不以空会话替代；原生 Pi 仍负责加载、消息、工具、压缩及执行。

这不修改 Pi SDK，也不重写 JSONL 的 cwd。若原历史工作目录已经不存在，原生 Pi 仍会拒绝；本批不创建假的旧目录、不自动迁移或改写历史路径。未来发布必须保留回退材料并单独处理工作目录迁移。

## 首次同工程载入

历史批次曾对首次同工程激活作狭义竞态修正。后续已将同工程读取与跨工程激活分离，AI 讨论时允许读取、几何操作仍等完整提交；详见 [工程读取与切换](WORKSPACE_SWITCH_zh.md)及 `.artifacts/workspace-read-result.json`。跨工程双侧保护未放松。

## 验证和边界

专项含原生 Pi/OCCT、排队后真实会话抢占、显式预览与实际原消息、写入未确认错误语义；真实浏览器验证默认不认领、历史变化拒绝、丢确认回复后刷新只读找回、不同 cwd 原生上下文、原几何真实显示与桌面/640px 可读性。正常 AI 建模与新建任务另以同候选回归，不混用旧前端数量。

仍未完成：日常旧归属迁移、缺失 cwd 的显式迁移、超过本地修复预算或存储不可用的离线治理、跨账户/服务实例的完整认证命名空间、任意外部/孤儿进程与恶意文件系统认证、原生多历史分支的专门选择界面、工业规模的持久索引和硬资源隔离。只支持用户核对当前会话所属当前工程，不提供把已绑定会话强行改绑到其他工程的入口。整体前处理工业化目标继续，复杂拓扑属性、工业脏几何/离散交叉、规模和完整安装升级仍在范围内；日常服务与用户页面保持原版本。
