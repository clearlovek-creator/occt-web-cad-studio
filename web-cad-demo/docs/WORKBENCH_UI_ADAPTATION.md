# 工作台界面适配说明

## 职责边界

本次将已确认的工作台设计接入真实应用，不是独立页面原型。

工程树管理数据，几何树管理几何及其建模历史，仿真管理只负责运行入口、状态和日志。求解设置、激励源、端口、边界等均由用户定义为属性类型；每种类型下直接挂载多个实例，不再单独重复建立一套仿真配置分类。

```text
工程管理
└─ 当前工程
   ├─ 变量 → 变量记录
   ├─ 材料 → 材料记录
   ├─ 坐标系 → 坐标记录
   ├─ 属性类型
   │  ├─ WavePort → Port1、Port2…
   │  └─ SolverSetup → Setup1、Setup2…
   └─ 仿真管理 [未运行]

几何树
├─ Copper
│  └─ Body → Feature → Boolean 输入历史
└─ 未指定材料
   └─ Body → Feature
```

类型名称不写死为特定仿真领域。仿真求解器尚未接入，界面明确提示这一状态；本次没有新增求解内核或伪造运行任务。

## 布局与入口

- 移除经典菜单栏，功能区分为工程、创建、变换、布尔、特征、网格、检查、视图、数据九类。
- 子命令固定为两行；空间不足时横向滚动，不增加第三行。
- 九种基础体、五种基础面有独立按钮，直接打开对应参数表单。
- 左侧同时展示工程树和几何树，宽度支持拖动与键盘调整；工程树区域可垂直调整高度。
- 中央视口保留体、面、边选择过滤器和标准视图。
- 参数窗口为可拖动、可最小化的非模态窗口；保持窗口打开时仍可拾取几何。视口缩小时重新限制窗口边界。
- AI 助手默认关闭，打开后占用独立侧栏并缩小视口，不覆盖几何。运行详情默认收起，对话历史、模式、复制及压缩上下文能力保留。
- 底部消息默认为一行，可展开查看完整错误。

## 树交互

共同使用 `ContextActions`，支持鼠标右键、行尾“⋯”、Shift+F10、方向键、Home/End 和 Escape。

工程记录支持新增、修改、复制、删除和引用查看。双击变量、材料、坐标系进入对应记录的独立编辑窗口，并恢复其已有值。内置记录不可删除；其他依赖保护由几何服务最终校验。

属性类型支持新增实例、编辑、复制、删除、类型文件导入导出。已有实例时禁止删除类型，已有字段的变更仍受服务端保护。实例支持编辑、复制、删除和定位关联几何。实例表单按类型生成 Bool、Int、Double、表达式、枚举和 Vector3 控件；实例不能修改或增加字段 key。

几何树按当前材料分组，修改材料不改变 Body ID、选中状态和特征历史。Body 行只保留名称、当前标记、几何显示、网格显示和更多操作。编辑、激活、关联属性和删除在右键菜单中。特征参数可双击修改；已消费输入历史不能独立删除或抑制。

## 网格行为

工程网格界面始终提交全部几何的共形剖分，不再通过当前选择生成互相独立的体网格。

网格结果默认不渲染，但所属 Body 的网格按钮在生成后就可用。图标改为九宫格线框：蓝色表示显示，灰色表示隐藏。几何隐藏暂时遮蔽其网格，再显示几何时恢复原有网格选择。

整体显示/隐藏只放在网格窗口。文件级几何修复、交叉处理、质量分析连接现有网关接口，输出独立文件，不替换当前工程几何。

## 验证方法

```powershell
npm run typecheck
npm run build
node --test --test-concurrency=4 tests/*.test.mjs
npm run test:ui
```

浏览器测试要求前端服务已启动，默认访问 `http://localhost:3000/`；测试会自行启动 8859 端口的隔离网关，并将浏览器的几何请求路由到临时测试工程，不修改用户工程。

可通过 `WORKBENCH_URL` 指定前端地址、`PLAYWRIGHT_MODULE` 指定 Playwright 模块、`WORKBENCH_CHROME_PATH` 指定浏览器。优先使用本地安装的 Playwright，当前桌面环境也可使用已提供的浏览器运行库。

截图输出在 `.artifacts/workbench/`，覆盖桌面工作台、网格图标、AI 侧栏、参数窗口及窄屏。

回归范围包括：两行工具栏与独立创建入口、双树布局、材料重新分组、字段类型与键约束、实例新增修改删除、坐标恢复、材料自定义字段、真实共形网格与可见性恢复、属性文件导入导出、项目保存/新建/打开、右键激活删除 Body，以及窗口草稿和边界保护。

删除 Body 时同步移除实体、边线与拾取缓存，并清除失效选择；`tests/render-cache.test.mjs` 防止出现树中已删除、视口仍残留边框的回归。

最终验证（2026-11-13）：类型检查与生产编译通过，207 项回归测试全部通过，20 项隔离工程浏览器流程全部通过，浏览器运行错误为 0。工作台新增及改造组件的定向静态检查通过；这不代表仓库内其他历史文件的全量静态检查已清零。编译仍有现有的资源体积与路由静态分类提示，不影响编译成功。

## 连接异常样例的报告内定位（候选，2026-11-16）

- 在现有网格验收区内以“结论 → 连接计数 → 样例”排序，不新增窗口或右侧面板。结论 14px/600 并随报告滚动保持可见；样例名称 13px/600，编号/归属 12px，动态计数使用等宽数字。沿用工作台蓝灰语义色、低对比边界与 4px 节奏，不另起主题。
- 使用原生 details、ol 和 button：定位目标至少 40px 高、64px 宽，提供 hover/active/focus/disabled/selected 状态；选中行和按钮用蓝色，与红色验收错误区分。最多 8 条，长编号/归属可换行，归属只展示前 4 个名称并明确余数；来源过期时使用来源 ID，避免将复用编号套上当前 Body 的名字。
- 定位复用既有透视诊断层：参与单元红色角点外框，异常公共三角面黄色突出。它是网格面而非 CAD Face，不加入拾取缓存、不修改几何外观/显隐，也不自动显示未通过的整份网格。保持 Body 显隐、来源身份、WebGL 恢复和清除语义一致。
- 仅有边界总量异常时不编造局部热点；缺损、截断、错误归属和超出视口表示范围的数据明确禁用。数值质量与连接拓扑分开，不能以“数值问题 0”代替完整验收。
- 主要实现：`MeshTopologySamples.tsx`、`model/mesh-topology.ts` 与既有 `mesh-quality-render.ts`；样例来自同一完整校验内的材料读取，不在点按钮时重扫大文件。独立浏览器入口 `scripts/verify-mesh-topology-location.mjs` 覆盖真实 CAD/Gmsh 基础模型、受管测试目录内 MSH/索引连接错误注入和真实 WebGL 像素，不是任意工业坏网格认证。

## 空间重叠的双单元定位（候选，2026-11-16）

- 延续报告内布局和已有蓝灰令牌：验收结论优先，后接明确的线性/高阶检查范围，再显示最多 8 对样例。不新增模态窗口、右侧面板或另一套显示开关。警告文案改称“验收警告”，避免将未覆盖的高阶空间检查误称为数值质量问题。
- 复用连接样例的原生 details/ol/button、2 列计数和行样式；名称 13px/600，编号/归属及图例 12px，计数 14px/600，4px 节奏，点击目标至少 40px。选中反馈保持蓝色；A/B 角色同时用文字和红/黄诊断几何区分，不仅靠颜色。Body 名称最多显示前 4 项并明确余数，窄屏编号可换行。
- 两个真实角点四面体独立生成、独立验证来源，共同聚焦；不创建假的坏质量记录来借用渲染颜色。单元读数显示两个编号及 A/B 图例；任一方隐藏即暂停整对，过期拒绝定位，清除/切换结果和 WebGL 恢复遵循同一来源约束。网格诊断仍不加入 CAD 拾取缓存。
- 后台样例携带经过原单元归属核验的 volumeTag 和持久 Body 身份；前端采用前再次检查双方编号、坐标、一致性和身份。缺失/截断/错误数据只显示原因，不构造单边或猜测位置的“半成功”定位。两者都来自同一完整文件校验，不因点定位重扫大网格。

## 远原点、小零件与一致的空间交互（候选，2026-11-16）

- 主要对象仍是工程几何，不新增面板、主题或额外原点设置。沿用蓝灰工作台、钢蓝 CAD、青色网格和黄色选择/诊断区分；Segoe UI 的 13px 控件、12px 元信息、14px 标题及 4px 节奏不变。修复针对工程人员导入远处坐标、查看小零件、选取同一真实拓扑的流程，而不是改变工程本身的位置。
- 显示缓冲区保存相对原点的 Float32 差值，Three 对象保持全局双精度位置。CAD、边线、选择/属性覆盖、二进制网格块、修复快照和历史输入沿用同一约定；它是显示实现，不是新的坐标系或建模特征。异常坐标不加入拾取缓存，主几何显示失败时清除旧图形并用现有消息区说明工程数据仍保留。
- “适应窗口”不再强制使用一单位的尺寸下限，导航最小/最大距离也随模型跨度更新，不让控制器把微小零件的相机推回 5 个单位之外；标准视图和显卡恢复采用相同约定。视图快捷按钮补齐可访问名称，但图标、位置与快捷交互不变。边的命中范围约 5 屏幕像素；隐藏、裁剪外和被不透明面遮挡的边不应命中，透明体后方可见边仍可选择。
- 浏览器验收使用真实十亿单位偏移的 8×6×4 Box 和 0.008×0.006×0.004 微小 Box，检查原生坐标、实际世界包围盒、可见像素、Face/Edge ID、真实 Gmsh 二进制网格、单元定位、历史输入及 GPU 恢复。自动化坐标辅助仅在显式验收事件中生成有界摘要，不每帧导出网格。极端全局跨度、源双精度损失和真实工业大装配仍需单独验收。

## 文件范围说明

属性类型 JSON 文件用于复用类型定义，不包含工程几何或属性实例。现有 XBF 项目入口与类型包入口保持分离；不要将类型包误当作完整工程备份。仿真求解器的运行适配与完整工程格式扩展不在本次界面适配中。
