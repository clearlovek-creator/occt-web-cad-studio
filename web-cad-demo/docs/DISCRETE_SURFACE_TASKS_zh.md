# 工程表面重构任务

表面交叉重构已接入隔离候选的工程任务系统和网格工具界面。任务使用当前工程全部几何，保存专用离散来源和重构结果，支持取消、历史读取、明确恢复和后台接口删除；不会修改 CAD 几何。日常服务未更新。

当前结果是保留来源的无交叉离散表面，不是封闭体域或四面体网格。结果固定保留 `normalMeshAdmitted: false`、`tetrahedralReady: false` 和 `appliedToCad: false`，不能调用普通网格显示、体网格质量查询或下载为 MSH。

## 界面操作

打开“网格”工具栏中的“剖分 / 修复 / 质量”，展开“表面交叉重构”，选择“重构全部几何表面”。界面使用默认的独立来源和修复策略，不套用上方四面体网格的尺寸、质量阈值或 Netgen 优化设置，也不增加确认弹窗。后台未明确声明引擎可用时，按钮禁用并说明原因，仍可读取已保存报告。

完成后显示来源修订、输入输出三角面数量、Body、Face 和 Solid 数量以及偏差警告。来源面表支持按 Body 筛选，每页 10 面；“定位”选择并高亮原 CAD 面，不是绘制重构结果。来源过期、后台尚未核对为当前或所属 Body 隐藏时禁止定位，不按面序号猜测新的几何。

任务记录将表面重构与诊断预览、体网格区分。表面结果不会送入普通网格显示，也不会覆盖已有体网格结果。运行时可在原任务区取消；关闭工具窗口不取消后台任务。

## 提交与查询

复用 `POST /api/documents/{documentId}/mesh/jobs`，不另建任务框架。请求示例：

```json
{
  "kind": "surface-reconstruction",
  "baseRevision": 12,
  "background": true,
  "surface": {
    "version": 1,
    "source": {
      "linearDeflection": 0.05,
      "angularDeflection": 0.15,
      "maxTriangles": 20000
    },
    "repair": {
      "snapGridSize": 40,
      "iterations": 5,
      "tolerance": 0.0000001
    }
  }
}
```

`surface` 可省略并使用以上默认值。请求不能附带局部选择、文件路径、体网格参数或任意来源标签。旧修订明确拒绝，不替换为新工程悄悄执行。`background: true` 返回任务编号，后续只读查询，不自动重发提交。

通过 `GET /api/mesh/jobs/{jobId}` 查询状态和概要，通过原工程任务列表读取历史。概要包含 Body、Face、Solid 数量，输入输出三角面数量、交叉检查、来源偏差及 CAD 离散估计警告数量。默认接口不返回完整点和三角面数组。

`GET /api/mesh/jobs/{jobId}/surface-report` 提供只读来源面页，接受 `bodyId`、`faceId`、`offset`、`limit`。默认每页 10 面，最大 25 面，单页回复最多 256 KiB；未知参数、文件路径、非法分页明确拒绝。每页在现有材料线程中重新核对完整来源和结果，再返回面身份、输入输出三角面计数、原 Solid 归属及估计偏差，不返回点、三角面坐标或整个来源文件。

一份输出三角面被同一 CAD 面的多个输入三角面引用时，该面只计一次；来自不同 Body 或 Face 的输出三角面分别计入各自来源，并计作共享输出。共享计数不是新的体域编号。通过 API 使用非默认策略时，实际参数以报告的 `sourcePolicy` 和 `repairPolicy` 为准。

`POST /api/mesh/jobs/{jobId}/cancel` 取消任务；运行中只停止该任务专属的 CGAL 进程，不关闭共享 CAD 内核。`DELETE /api/mesh/jobs/{jobId}` 明确删除已结束任务及其所属材料，活动任务必须先取消并核验退出。

## 排队与资源

表面任务和现有 Gmsh 任务共用执行队列、任务容量和磁盘预约。当前后台默认同时执行一个原生任务。表面来源捕获另限两份；在等待磁盘检查之前即保留名额，不把多份大型来源快照长期积压在内存队列中。正在准入的任务同时占用目录容量，跨工程并发不能绕过该上限。

CAD 来源捕获在已有工程串行队列中完成，排队阶段可取消。捕获已进入共享 CAD 内核时，不为取消而杀掉该内核；导出返回后检查取消状态，不继续重构。CGAL 计算不占用 CAD 操作队列。

原生内存、协议和退出约束见 [开源集成](DISCRETE_SURFACE_INTEGRATION_zh.md)。完整来源快照最多 20 MiB，保存的完整结果最多 96 MiB；这些是单任务及材料预算，不是整机总内存承诺。

## 保存和重启

任务目录固定派生自工程和任务编号，保存 `metadata.json`、`surface-source.json`、`result.json` 及完成凭据。客户端不能指定这些位置。来源包含完整清单、几何摘要、输入摘要和实际内核身份，详细语义见 [CAD 表面来源绑定](DISCRETE_CAD_SOURCE_zh.md)。

排队任务只保留磁盘来源证明；开始计算时重新核对原文件。保存阶段在线程中核验完整来源、算法结果、资源证明及正常退出，再发布结果。进程未核验退出、取消、超时或来源损坏均不能发布成功。文件占用不会触发几何重算或盲目写入重试。

重启时已完成任务保持隐藏，只读核对原结果；未完成任务保留为中断，不自动重跑。几何后续改变会使原结果标记为过期，但不改写原来源。来源或结果字节被修改时明确拒绝，原材料保留。

算法已完成但完成凭据保存失败时，可复用原有 `recover-completion` 接口，以原失败状态摘要和新请求 UUID 明确恢复。恢复重新核对保存字节及预算，不重新导出或调用 CGAL。

## 运行库与许可

候选后台的原生清单增加第二版格式，分别封存几何、Gmsh 和离散表面引擎。离散引擎具有独立 DLL 目录和捕获的开源许可材料；启动前及每次创建客户端时检查实际文件，内容变化即拒绝，不从系统 PATH 借用替代库。

旧版两套内核格式仍精确支持，不能通过继承环境或工程 `.env` 为旧封存后台临时启用新引擎。未配置时任务返回 `SURFACE_WORKER_UNAVAILABLE`。开发运行只接受明确指定且完整独立的运行目录。

选择 CGAL 6.1.2 的 GPL-3.0-or-later 路线，不购买授权，也不主张独立进程构成许可豁免。当前捕获许可文本、实际包信息和文件摘要，但完整对应源码与构建材料尚未齐备，公开分发资格保持 `false`。

## 验证与下一步

真实隔离后台已验证交叠 Box、混合 Solid 与 Sheet、来源归属、取消、重启、中断不重跑、明确完成恢复、过期、损坏拦截和所属目录删除。页面另验证真实面高亮、分页、三种宽度的可读性、隐藏和过期保护、错误回复拒绝、取消及不可用引擎状态。当前准确前后台版本与最终回归见 `.artifacts/surface-report-result.json`；前批任务基础保留在 `.artifacts/discrete-task-result.json`。

已完成结果的来源或结果文件暂时被占用，或发生明确的权限、磁盘和句柄资源错误时，材料线程与发布层返回 `MESH_ARTIFACT_IO`，不将已完成任务改写为损坏。页面保留概要，提供“重新读取报告”；解除真实 Windows 独占句柄后可读取原文件，元数据与结果字节不变，也不调用 CGAL。文件缺失、摘要改变和来源证据不合法仍是完整性失败，不能用重试掩盖。生成阶段的写入失败不自动重做算法；仅完成凭据失败使用原有明确恢复机制。

隔离的[体域分区原型](VOLUME_DOMAIN_RESEARCH_zh.md)已分别导出含空腔的连通体，[共形四面体原型](VOLUME_TETRA_RESEARCH_zh.md)已核对实际界面节点、单元归属与体积守恒，尚未接入本任务。部分样本有低质量单元；后续补齐质量改善与准入、重构结果只读可视化、材料决策和正式任务链路，才能进入正常网格显示。任意工业脏几何、全局资源规模和完整开源分发材料仍需独立验证。
